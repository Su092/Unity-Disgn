# 数值门：字段含义与口径陷阱

配套 `scripts/blender_gate.py`。所有门返回三态：`pass` / `fail` / `degraded`。

> **degraded 不是通过，也不是失败 ⇒ 要补查。**
> 退出码：`pass=0` / `fail=1` / `degraded=2`，方便 CI 串联。

## 0. 快速开始

```powershell
$b = "E:\SteamLibrary\steamapps\common\Blender\blender.exe"
$skill = "E:\Unity Development\.codex\skills\blender-asset-pipeline"
$g = Join-Path $skill "scripts\blender_gate.py"

# 先验门本身（必须 11/11）
& $b -b --factory-startup --python $g -- selftest

# 单门
& $b -b model.blend --python $g -- mesh     --objects Chair
& $b -b model.blend --python $g -- normals  --objects Chair
& $b -b model.blend --python $g -- measure  --objects Chair --expect 400,400,800 --tol-mm 3

# 全跑 + 落 JSON
& $b -b model.blend --python $g -- all --min-mm 1.2 --out gate.json
```

`--objects` 接受：逗号分隔对象名 / **集合名** / `*` / 省略（= 场景内全部网格）。

## 1. 门①：网格健康 `-- mesh`

| 字段 | 含义 | 通过判据 |
|---|---|---|
| `boundary_edges` | 只属 1 个面的边（= 开边） | 闭合件必须 0 |
| `nonmanifold_edges` | 属 >2 个面的边 | **必须 0** |
| `degenerate_faces` | 面积 ≈ 0 的面 | **必须 0** |
| `loose_verts` | 不属任何面的点 | **必须 0** |
| `loose_edges` | 不属任何面的边 | **必须 0** |
| `tris` | 三角数（对预算） | 看你自己的预算 |
| `closed` | `boundary==0 and nonmanifold==0` | 壳类件应 true |

**口径陷阱**：`boundary_edges > 0` **只说明是开放网格**，对壳类件才是缺陷。
有意的开口件（薄片、开口罩）请只把 `nonmanifold` / `degenerate` / `loose_*` 当门。

## 2. 门②：法线（逐连通壳）`-- normals`

**这是最容易被读错的一道门。**

| 字段 | 含义 |
|---|---|
| `shell_count` | 连通壳数 |
| `shells[].closed` | 该壳是否闭合 |
| `shells[].signed_volume` | 该壳有符号体积；**< 0 ⇒ 朝内** |
| `shells[].nested` | 是否被某个更大的正向壳包住（合法空腔） |
| `shells[].state` | `pass` / `fail` / `n/a` |

**判据**：

- 有任一**非嵌套**闭合壳 `signed_volume < 0` ⇒ `fail`（先 recalc 再复检）；
- 全部壳未闭合 ⇒ `degraded`（"整体朝向"无意义）；
- 部分未闭合 ⇒ `degraded`（**那部分判不了，不算通过**）；
- 其余 ⇒ `pass`。

**★ 为什么必须逐壳**：聚合 `signed_volume` 把所有壳**相加**。
大正向壳（+8）+ 分离的小反向壳（−1）= +7 > 0 ⇒ 反向那块被吞掉。
`selftest` 里有一条专门的用例守这个（`big+inverted small`）。

## 3. 门③：埋面 `-- buried`

| 字段 | 含义 |
|---|---|
| `buried_count` | 从面中心沿**外法线**打射线、被别的几何挡住的面数 |
| `buried[]` | 明细：面索引 / 打到谁 / 距离 |

**为什么单列**：`Delete Loose` **删不掉**这些（它只删不属于任何面的点/边，**一个面都不删**）。
`select_interior_faces()` 也不解决（它只对"每条边都有 >2 个面用户"那类有效）。

**处置按成因分**：

| 成因 | 正确处置 |
|---|---|
| join / 复制出来的重叠壳体（最常见） | **Boolean UNION** 并成一个实体；**别"选中再删"** —— 实测删掉埋面后留下 8 条开边（壳被捅开），还得补面 |
| Boolean 残留碎片 | 换 `solver='EXACT'` 重跑，或 `merge_doubles` + `dissolve_degenerate` + `delete_loose` + `recalc_normals` |
| 手滑多做的内壁 | 用本门找出来删，**删完必须补面或改走布尔**，并复检开边 |
| 起因不明 | 先看 `nonmanifold` / `degenerate` / `boundary`；**自交才是"互相穿进对方"的机器判据** |

**判据**：删内部面之后 `mesh` 必须仍 `pass`（`boundary_edges=0` / `nonmanifold_edges=0`）。
只盯"面数变少了"而不管开边，等于把穿模换成破面。

## 4. 门④：自交 `-- selfint`

| 字段 | 含义 |
|---|---|
| `pair_count` | 三角级相交对数 |
| `pairs[]` | 相交面索引对 |

**口径**：BVH `overlap` 得到粗筛，**相邻共点面已排除**（否则每个正常面都会被判自交）。

**注意**：
- **贴合接触可能给出 1+**。设计上允许的接触要**白名单化**，别拿 `pair_count` 当穿模开关；
- 本门是**单体自交**。跨对象的干涉要用装配级检查（见 §7）。

## 5. 门⑤：壁厚 `-- thickness --min-mm 1.2`

| 字段 | 含义 |
|---|---|
| `min_mm` / `median_mm` | 采样点的内向射线命中距离 |
| `samples` | 有效采样数 |
| `samples_below` | 低于阈值的采样数 |
| `notes[]` | 降级原因 |

**口径陷阱**：

- 没打到对面（开放曲面）⇒ `degraded`，**不是 fail**（薄片本来就没厚度）；
- **`min_mm` 低于测量分辨率时结论不可信** ⇒ 传 `--resolution-mm` 会判 `degraded`。
  **别拿粗网格下细结论**；
- 曲率大处会**低估**（射线斜穿）。

## 6. 门⑥：尺寸 `-- measure --expect x,y,z --tol-mm 3`

| 字段 | 含义 |
|---|---|
| `min_mm` / `max_mm` | 世界 AABB 端点 |
| `size_mm` | 三轴尺寸 |
| `dev_mm` | 与 `--expect` 的逐轴偏差 |
| `out_of_tolerance[]` | 超差项明细 |

**★ 用 `matrix_world @ v.co` 求世界 AABB，不用 `obj.dimensions`。**
后者是"局部 bbox × scale"，**不含旋转** —— 旋转过的件会给错数。
（这也是"换一条计算通路"的最典型例子：构建用 `dimensions`，验证必须用 `matrix_world`。）

## 7. 装配级补充门（`blender_gate.py` 目前不覆盖，另写或手测）

单件跑门①–⑥；装配完成后加跑以下三项。

### 7.1 浮空

**判据**：无悬空件（可见浮块 ≈ 最长 bbox 边 ≥ 全模型 1%）。

**口径陷阱**：
- **别拿"连通分量数 = 1"当判据** —— 贴而未焊天然是多分量；
- 顶层**没有**统一 `state` 这类字段时，要自己定判据并写进回执。

### 7.2 干涉

**判据**：无异常互穿；允许的隐藏交叠**白名单化**。

**口径陷阱**：`unresolved` = **判不了**，不是"无干涉"；贴合接触常给 `unresolved`。
`analyzed=false` ≠ 无重叠。

### 7.3 包络 / 尺寸漂移

**判据**：关键 bbox 与 spec 偏差 ≤ 公差（工业件常取 ±3 mm）。
**用门⑥ 的 `size_mm` 对 spec 逐条比**，不要目测。

## 8. 三态判定速查

| 你看到的 | 它意味着 | 你要做的 |
|---|---|---|
| `verdict=pass` | 查完了，没缺陷 | 放行 |
| `verdict=fail` | 查完了，确有缺陷 | 看 `defects` / `counts` 里非 0 的字段，改几何 |
| `verdict=degraded` + `error` | 参数错 / 找不到对象 | 改参数 |
| `verdict=degraded` + `notes` | 判不了（精度不足 / 未闭合 / 无采样） | **补查**：加密网格、闭合网格、提高采样 |
| `pair_count=null` | 判不了，不是 0 | 同上 |
| `min_mm=null` | 没打到对面，不是"厚" | 闭合或换门 |

## 9. 把门接进 CI

```powershell
& $b -b model.blend --python $g -- all --min-mm 1.2 --out gate.json
$code = $LASTEXITCODE
if ($code -eq 1) { Write-Error "有缺陷，看 gate.json" }
if ($code -eq 2) { Write-Error "判不了（degraded）⇒ 补查，不许当通过" }
```

**`degraded` 必须让 CI 变红** —— 否则"没查完"会静默变成"通过"，这正是这套纪律要防的事。
