# 修改器栈序与网格清理

## 1. 修改器栈：不存在通用顺序

> ★ **纠正一条被写死的"固定链"**：老经验让人背
> `Mirror → Array → Solidify → Bevel → Subdivision → Boolean`。
> **不存在这样一条通用顺序。**
>
> 修改器栈是一个**按目标函数排序的求值链**：同一个基础网格，只换两三条的顺序，
> **拓扑和尺寸都会变**。

### 1.1 实测（Blender 5.2.2，同一个 1 m 立方体）

| 顺序 | verts / faces | bbox 最长边 |
|---|---|---|
| Bevel(0.2 / 2 段) → SubSurf(2) | **866 / 864** | **0.9904 m** |
| SubSurf(2) → Bevel(0.2 / 2 段) | **98 / 96** | **0.8395 m** |
| Solidify(0.03) → Bevel(0.05 / 2 段)（平面） | **56 / 54** | — |
| Bevel(0.05 / 2 段) → Solidify(0.03)（平面） | **8 / 6** | — |

两边的结果**都对**，取决于你要的是"圆角被细分保留"还是"细分后的低模再被倒圆"。
`bbox` 差 **15%** 说明这不只是面数问题。

⇒ **顺序靠目标决定，不靠背。**

### 1.2 按目标定顺序

| 目标 | 顺序（相对） | 为什么 |
|---|---|---|
| 镜像件要浑然一体 | **Mirror 在前**，Bevel / SubSurf 在后 | 让镜像缝先焊成连续面，再统一倒角/细分；反过来缝处会被当成自由边处理 |
| 重复阵列的每个单元各自带倒角 | **Bevel 在前**，Array 在后 | 后级只复制前级的结果；反了则倒角作用在"整排"的接缝上 |
| 薄壳（钣金/壳体）边缘圆润 | **Solidify 在前**，Bevel 在后 | 先有厚度才有"实心边"可倒；实测反着放倒角基本被吃掉（54 面 → 6 面） |
| 光滑曲面但要保棱 | **Bevel 在前**，SubSurf 在后 | 倒角提供支撑边，细分才不会把棱圆掉 |
| 分面硬表面（装甲板/军模） | **不要 SubSurf** | 细分会把棱边全部圆成"肥皂"⇒ 走小倒角 + 平坦着色 |
| 布尔开孔 | Boolean **尽量靠后**、导出前再 apply | 保持非破坏；布尔后的 n-gon 还会影响后续细分 |
| 拓扑定型后再镜像 | **apply Mirror 在改拓扑之前** | 拓扑一变，镜像缝的对齐就不保证 |

### 1.3 顺序对不对，用回执判

不靠背，靠对拍：

```python
import bpy
dg = bpy.context.evaluated_depsgraph_get()
ev = obj.evaluated_get(dg)
me = ev.to_mesh()
print("verts", len(me.vertices), "faces", len(me.polygons))
# bbox 也要取求值后的
ev.to_mesh_clear()
```

与你的目标数值对拍，**再加跑 `blender_gate.py` 的数值门**。
**改了顺序就重跑一遍门。**

### 1.4 症状表

| 症状 | 修法 |
|---|---|
| 一看就是默认方块 | 加 Bevel（0.02 m / 3 段）+ SubSurf（**仅限光滑件**） |
| **装甲棱边被圆掉、像塑料玩具** | 分面件误用了 SubSurf → 删掉 SubSurf，改小倒角 + 平坦着色 |
| 圆形上出现夹点 | Bevel 要在 SubSurf **之前** |
| 渲染出黑面 | 重算法线；先查有符号体积判断是不是整体朝内 |
| 布尔产生 n-gon | apply 布尔后改回四边面，再 SubSurf |
| 对称破掉 | 用 Mirror 修改器，不要复制再翻转 |
| 网格里有看不见的内部面 | ★ **不是 `Delete Loose`**（见 §2） |
| 细分后发皱 / 塌陷 | 缺支撑边：加环切固定结构，别继续加细分层级 |
| 阵列首尾对不上（履带/链节） | 用参数化销轴弦长路径，不要靠 `FIT_CURVE` 阵列 |
| headless 里 ops 报 context/poll 错 | 改 bmesh / data API，或用 `temp_override` |

## 2. 删除内部面：`Delete Loose` 是错的（★ 老经验教错了）

老经验写"网格里有看不见的内部面 → Clean Up → **Delete Loose**"。**这是错的**：
`Delete Loose` 只删除**不属于任何面的顶点与边**，**一个面都不会删**。

### 实测（Blender 5.2.2）

Blender 自己打印的是一行 `Info`：

| 场景 | 内部面 | 跑 `delete_loose` 后 |
|---|---|---|
| 立方体里塞一张独立浮动四边形 | 1 张 | `Info: Removed: 482 vertices, 992 edges, **0 faces**` → 那张面还在 |
| 两个重叠立方体 join（每个壳各有一面埋进对方） | 2 张 | `Info: Removed: 0 vertices, 0 edges, **0 faces**` → 面数仍是 12 |

顺带否掉第二个常见误解：`bpy.ops.mesh.select_interior_faces()` **也不解决**这个问题 ——
上面那个 join 出来的重叠对，它选中 **0** 张面（它只对"每条边都有 >2 个面用户"那类才有效）。

### 正确做法：按成因分

```python
import bpy, bmesh
from mathutils.bvhtree import BVHTree

def buried_faces(obj, eps=1e-5):
    """埋在实体内部的面：从面中心沿**外法线**打射线，命中 = 该面被别的几何挡住了。
    （clean cube -> 0；两个重叠立方体 join -> 恰好 2）"""
    bm = bmesh.new()
    bm.from_mesh(obj.data)
    bm.faces.ensure_lookup_table()
    bvh = BVHTree.FromBMesh(bm)
    out = []
    for f in bm.faces:
        c = f.calc_center_median() + f.normal * eps
        loc, nor, idx, dist = bvh.ray_cast(c, f.normal, 1e6)
        if idx is not None and idx != f.index:
            out.append(f.index)
    bm.free()
    return out
```

> 这就是 `scripts/blender_gate.py -- buried` 的实现。直接用脚本即可，不用抄上面这段。

| 成因 | 正确处置 |
|---|---|
| **join / 复制出来的重叠壳体**（最常见） | **Boolean UNION**（或 `mesh.intersect` 的 Boolean）把两壳并成一个实体；**别用"选中再删"** —— 实测删掉埋面后留下 **8 条开边**（壳被捅开了），还得再补面 |
| Boolean 求解残留的碎片 | 换 `solver='EXACT'` 重跑，或 `merge_doubles` + `dissolve_degenerate` + `delete_loose` + `recalc_normals`（这里的 `delete_loose` 干的是它**真正**该干的活：清孤立点/边） |
| 建模时手滑多做的内壁 | 用 `buried_faces()` 找出来删，**删完必须补面或改走布尔**，并复检 `boundary_edges` |
| 起因不明 | 先跑 `-- mesh` 看 `nonmanifold_edges` / `boundary_edges`；**`-- selfint` 才是"互相穿进对方"的机器判据** |

### 判据

删内部面之后 `-- mesh` 必须仍是 `pass`（`boundary_edges=0` / `nonmanifold_edges=0`）。

**只盯着"面数变少了"而不管开边，等于把穿模换成了破面。**

## 3. 标准清理序列

```powershell
# 1) 先看现状（别急着改）
& $b -b model.blend --python $g -- mesh --objects Body

# 2) 清理（bmesh，headless 安全）
```

```python
import bpy, bmesh

def clean(obj, merge_dist=1e-4):
    bm = bmesh.new()
    bm.from_mesh(obj.data)

    bmesh.ops.remove_doubles(bm, verts=bm.verts, dist=merge_dist)
    bmesh.ops.dissolve_degenerate(bm, dist=1e-6, edges=bm.edges)
    bmesh.ops.recalc_face_normals(bm, faces=bm.faces)

    bm.to_mesh(obj.data)
    bm.free()
    obj.data.update()
```

```powershell
# 3) 复检（必须回到 pass）
& $b -b model.blend --python $g -- all --objects Body
```

**顺序固定：合并重复点 → 溶解退化 → 重算法线 → 复检。**
先重算法线再合并，等于在脏拓扑上算朝向，结论不可靠。

## 4. 命名与结构约定

- 对象一建就命名，用 `GEO-` 前缀（`GEO-blade` / `GEO-hull`）；
- blockout 与成品**分集合**（`COL_Blockout` / `COL_Geo`）；
- 布尔 / 导出前应用变换（Apply Scale）；
- 拓扑改动前先存快照（`.blend` 副本或版本控制）。

**这些不是风格问题**：`--objects` 按集合/名字取对象，命名混乱会让门测错东西。
