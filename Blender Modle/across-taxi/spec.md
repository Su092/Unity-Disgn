# 蜘蛛侠·纵横宇宙风 —— 风格化出租车（across-taxi）规格（冻结）

> 项目：`E:\Unity Development\Blender Modle\across-taxi`
> 本文件是 `build_taxi.py` 的**唯一数值来源**。改数值必须同时改脚本 `SPEC`，
> 否则量测门（audit_measure）的期望值就与模型脱钩。
> 单位：**全部 mm**；Blender 场景 1 BU = 1 m（`unit_settings.scale_length = 1.0`）。

原始输出 `refs/probe-side.json` / `refs/probe-front.json`。

**标定口径（重要）**：参考图没有标尺，`img_digest` 判 `needs_scale`。
本 spec 的做法是**先选定车长 L = 5200 mm 作为标定锚**，其余尺寸按像素比例换算：

```
px_per_mm = 1630 px / 5200 mm = 0.31346      （侧视）
```

因此本文件里的 mm 是"**以 5200 车长归一化的比例换算值**"，不是照片实测毫米。
除车长外，每一项都保留了 px 原始值，可复算。

## 12. 已知边界

1. 参考图是插画（有墨线、网点、色散），不是正交三视图；比例按"选定车长"归一化，
   误差约 ±3%。因此量测门容差放到 ±6 mm。
2. 车厢内部（座椅/方向盘）不做几何，玻璃为深色不透明面 —— 参考图里的内饰是画出来的。
3. 描边（inverted hull）、半调网点、色散都是**渲染层**（`scripts/lookdev.py`），不进网格、不导出。
4. 轮胎/轮毂是回转体，无胎纹与螺栓 —— 风格与面数预算都不需要。
