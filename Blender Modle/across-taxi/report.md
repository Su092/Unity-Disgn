# 验收报告 · 《蜘蛛侠：纵横宇宙》风格出租车（across-taxi）

> 目标：按参考图建一辆可交付的风格化出租车（1 个网格对象 / 5 个闭合壳 / 带 UV 与烘焙贴图），
> 并把"像不像"落成数字。
> 结论：**几何门全 pass**（mesh / measure / normals）；同机位侧视 **IoU 0.9318 / Dice 0.9647**，
> 按 visualreport 默认判定线（pass 0.95）记 **fail**，原因与可接受性见 §5。

## 3. 建模流水线

```
spec.md（冻结尺寸）
  → build_taxi.py：断面放样 body/cabin → 22 mm 倒角 → 30+ 件细节 UNION → 轮拱解析切削
                   → 车轮（胎+毂+槽+盖）UNION，4 个独立壳 → join
                   → clean_mesh（折叠退化边）→ UV 分岛 → EMIT 烘焙 → 存 .blend
  → lookdev.py：Freestyle 墨线 + 硬光 + 色散/泛光/曲线 + 同机位对比帧
  → export_asset.py：FBX/GLB/OBJ + basecolor + manifest(md5)
```

风格落在三处（可验证）：

1. **几何**：夸张比例（长宽高比 2.67 : 1 : 1.15）、大块面 + 22 mm 倒角、凸起的黑白棋盘带；
2. **描边**：Freestyle 轮廓/折边/材质边界线，粗 3 px，接近参考图的漫画墨线；
3. **后期**：Lensdist 色散（边缘红青分离）+ Fog Glow 微泛光 + Curves 提对比。

## 5. 同机位对照（IoU）——为什么记 fail

`visualreport_report`（ref=侧视参考图，render=`renders/cmp-side.png`，同正交机位、同裁切、
透明底、裁掉地面阴影带 y≤815）：

| 指标 | 值 | 判定线 |
|---|---|---|
| IoU | **0.9318** | pass ≥0.95 / fail <0.85 |
| Dice | 0.9647 | — |
| 缺失面积 | 3.1% | ≤2.0% |
| 多余面积 | 3.9% | ≤2.0% |
| 边界平均偏差 | 3.85 px（≈12 mm） | — |

verdict = **fail**，触发项是"缺失 3.1% / 多余 3.9%"（IoU 本身已过 fail 线）。

**为什么不继续压到 0.95**：剩余差异的两大来源不是模型错误，而是参考图自身：

1. 参考图带**落地投影**（y 740–833 一片暗块），掩膜把它算成"车有、渲染无"；
   已通过裁掉 y>815 去掉大部分，仍有残留；
2. 参考图是**手绘插画**：墨线外扩、半调网点、边缘色散都会让掩膜边界抖动 2–4 px；
   正/侧/后三视图之间本身不自洽（H/W 与 H/L 冲突，见 §2）。

3.85 px 的边界偏差对应约 12 mm，已达到"参考图本身画不准"的量级。
所以本项按 **fail 如实记录**，不作为"通过"；要过 0.95 需要更换量具口径（例如只比
belt/roof 特征线，或先给参考图抠背景+去投影），不是继续磨几何。

## 6. 过程记录（踩过的坑，都是实测）

| # | 症状 | 根因 | 处置 |
|---|---|---|---|
| 1 | 镀铬全黑（保险杠/亮条/轮毂） | `DIFFUSE(color-only)` 烘焙对 metallic=1 返回**纯黑**，又把烘焙图接进 Base Color | 改 **EMIT** 烘焙（纯反照率）；并加"上亮下暗"环境让金属有东西可反射 |
| 2 | 车身颜色发奶油 | 默认 AgX 视图变换把高饱和黄洗掉 | `view_transform='Standard'`，并关 look |
| 3 | UNION 后车身直接消失（956→0 面） | 格栅框用 4 根**互相重叠**的盒子拼，操作数自交 → 求解器把 target 吃掉 | 写 `rect_ring()` 单个矩形垫圈实体；并在每次 UNION 后断言面数不崩 |
| 4 | 车身不是单壳（1→3、1→7） | 细节件浮在车身表面**之外**（腰线条/立柱条/镜子杆在收分斜面之外） | 逐件打印壳数跳变定位；把件做成"跨过表面"（内插 ≥5 mm），立柱改为**刷漆分区**不建几何 |
| 5 | 自交 136 对 | 轮拱内壁 y=620 与轮胎（575–825）互穿；轮胎穿过车身底面 z=364 | 轮拱内壁外移到 **552**（轮胎内沿 575 ⇒ 23 mm 间隙） |
| 6 | 退化面 4 个 | 布尔残留的零面积面 | `clean_mesh()`：`dissolve_degenerate(0.02mm)` + `remove_doubles` |
| 7 | inverted-hull 描边把整车涂黑 | Solidify 的 flip 与手动 `recalc_face_normals`/`normal_flip` 叠加，法线又被翻回朝外 | 放弃 hull，改 **Freestyle**（同时能出内部折边线） |
| 8 | 同机位 IoU 只有 0.79 | 对比帧从 −Y 侧拍，得到**镜像图**（参考图车头朝左） | 改从 +Y 侧拍 → 0.79 跳到 0.91；再修引擎盖坡度 → 0.9318 |
| 9 | 引擎盖像一块平板 | 顶面占宽 0.93w 且前段不变 | 剖面加**逐站冠顶系数**（前段 0.74–0.85），zt 不动 ⇒ 侧视轮廓不变、正面读成圆肩引擎盖 |

## 7. 已知边界（不藏）

1. 参考图是插画，比例按"选定车长"归一化，误差约 ±3%；因此量测容差放到 ±6 mm。
2. **车厢内部不做几何**（座椅/方向盘/仪表），玻璃是深色不透明面 —— 参考图里的内饰是画出来的。
3. 顶灯箱**无 "TAXI" 字**：参考图的灯箱是空白黄罩，按图不刻字（旧项目刻了字，这次以参考图为准）。
4. 描边/网点/色散是**渲染层**（`lookdev.py`），不进网格、不进 FBX/GLB。
5. 轮毂是回转体 + 暗槽 + 中心盖，没有螺栓/胎纹（风格与面数预算都不需要）。
6. 车门缝是**凸/贴面细条**，不是刻槽（刻槽会削薄壁厚）。
