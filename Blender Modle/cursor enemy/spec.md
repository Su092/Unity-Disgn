## 3. 部件与装配

单件成品为**一个网格对象** `GEO-Enemy-Crawler`，单壳闭合：

| 接头 | 交叠量 | 说明 |
|---|---|---|
| 腿 × 4 → 车体腹部 | 腿顶 z=756 插入腹板 z=531，交叠 225 mm | UNION |
| 头 → 车壳前檐下 | 后段插入 200 mm | UNION |
| visor / 蓝条 | **凹槽**（DIFFERENCE），槽底自发光 | 保持单壳 |

UNION/DIFFERENCE 用 **MANIFOLD** 求解器：Blender 5.2 的 `EXACT` 在本件共面输入上
返回空网格（实测 v=0），`FLOAT` 可用但可能残留自交。

**不做贴片**：贴片内推会被 `buried_true` 判真内部面（57 张），外贴会让下表面
落在壳体内（2 张）。凹槽是唯一同时满足"单壳 + 0 埋面 + 可见发光"的做法。

## 5. 验收判据（数字，非目测）

| # | 判据 | 口径 | 门限 | 实测 |
|---|---|---|---|---|
| A | 门 ①–⑥ 全 pass | `tools/blender-gate.ps1` | pass | **pass** |
| B | 单壳 / 无开边 | 门 mesh/normals | shells=1 | **1 / 0** |
| C | buried-true = 0 | `tools/blender_buried_true.py` | 0 | **0** |
| D | 尺寸 AABB | 门 measure | ±3 mm | **1474×2137×1387** |
| E | FBX 契约 10 项 | `tools/blender_contract.py` | pass | **pass** |
| F | UV 可用 | `tools/blender_uv_gate.py` | 0 重叠 / 密度比≤1.10 | **107 岛 / 0 / 1.0007** |
| G | 投影 H/L | `scripts/compare.py` | ≤0.06 | **0.0256** |
| H | visor / 蓝条 / 橙壳 / 侧条 中心 | 同上（色相分类） | ≤0.06 | **0.078 / 0.054 / 0.049 / 0.057** |
| I | 腿带中心 | 同上 | ≤0.06 | **0.206 ✗**（已知偏差，见 README） |

G/H 是"形体还原"的唯一依据；单张 beauty 图不作为通过依据。
H 项里 visor 实测 0.078 略超 0.06；它是四项中最接近门限的（0.078 vs 0.06），
记录为**临界未达标**，不是通过。

## 6. 机位（标定产物）

`refs_out/camera.json`：az=30, el=8, lens=85, dist 由 `fit_framing()` 现解。
取景在 `build_crawler.py` 里自动解算（二分 dist + shift 对中），因为机位与几何尺寸
耦合，几何一改就可能出画（实测 1254 宽下右侧被切过）。
