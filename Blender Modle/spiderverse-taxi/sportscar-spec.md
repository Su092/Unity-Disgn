# 红色复古跑车 · 规格（冻结）

> 与出租车同属 `spiderverse-taxi` 项目；交付对象 `GEO-SportSpider`。
> 单位 mm；场景 1 BU = 1 m。任何数值改动必须同步改 `scripts/build_sportscar.py`。

## 0. 风格目标

《纵横宇宙》语言下的 **1960 年代敞篷跑车**：低趴、长引擎盖、翼子板峰、小风挡、真敞篷舱口、
侧出排气管、镀铬五辐轮。与出租车并排放在同场景，验收"两种车体语言共用同一套门"。

| 风格特征 | 几何落点 | 判据 |
|---|---|---|
| 低趴 | 甲板 758~830，风挡顶 1215 | 4200 × 1780 × 1215 ±3 mm |
| 长鼻短尾 | 引擎盖 x 340→2050（占全长 41%），座舱靠后 | §3 断面表 |
| 翼子板峰 | 轮心上方 zt=830，压住轮拱（顶 800） | 见 §3 约束 |
| 敞篷 | 真开口盲腔，可见双座与两个头枕鼓包 | §4 |
| 圆灯 + 镀铬 | Ø156 圆灯、椭圆格栅环、细保险杠 | 真几何 UNION |
| 侧出排气管 | z=340、y=±845，露出 30 mm | 不穿轮拱 |

## 0b. 参考图（链式生成，先图后模）

参考图**串行**生成：先出主视角，再把它当参考图生成其余视角。

| 步骤 | 命令 / 产物 |
|---|---|
| ① 主视角 | `.cursor/skills/apimart-image/scripts/apimart_ref_chain.py` 提交 anchor → `refs/sport-ref-anchor.png`（3/4 前视，无参考） |
| ② 其余视角 | anchor 的图片 URL 作为 `image_urls` 提交 → `refs/sport-ref-side.png` / `-front` / `-rear34` |
| ③ 回执 | `refs/chain-receipt.json`（task_id / URL / 耗时；URL 24h 内可复用） |
| ④ 量测 | `scripts/measure_ref.py` 出 H/L、最高点位置、上轮廓 11 点（`--ascii` 可直接看掩膜） |
| ⑤ 对拍 | `scripts/ref_compare.py` 比"参考图 vs 模型剪影（`silhouette.py`）" |

为什么串行：批量并行时每条只拿到同一段文字，灯形、轮辐、软顶高矮各画各的；
把已出的图作为输入参考后，四张图的车体轮廓与配件位置明显更一致。

## 4. 敞篷舱口 / 风挡

- 舱口：DIFFERENCE 盲腔 `x −700→200 / y ±430 / z 520→1000`。腔底 520，底面（170）保留 350 mm，
  **不破底 → 仍水密**。腔后壁离后轮拱 110 mm，前壁离风挡底梁 40 mm。
- 风挡底梁：`x 240→340 / y ±500 / z 735→805`（压甲板 758 以上 23 mm）
- A 柱：**后倾整片**（XZ 梯形棱柱，非阶梯方盒）`(345,760)-(295,760)-(-25,1200)-(25,1200)`，
  厚 50，`y 455→505`
- 风挡顶梁：`x −60→40 / y ±490 / z 1185→1215`
- 风挡玻璃：四角 `(330,±470,795)` → `(−20,±455,1192)`，沿法线厚 ±20。
  上下各嵌进梁 10 mm，左右钻进 A 柱 15 mm（不与框共面）
- 低篷包：`x −1010→−730 / y ±480 / z 735→845`，车漆色（折叠状态，只在舱口后抬起）
- 双座：垫 `x −680→−340 / y ±(60..360) / z 505→610`；
  靠背 `x −690→−575 / y ±(75..345) / z 590→900`（**y 与垫错开 15 mm，避免共面退化面**）；
  头枕鼓包 `x −690→−565 / y ±(90..330) / z 880→1010`
- 顺序：车身 UNION 完 → 挖舱口 → 再并座椅。
  挖口前并座椅会被实心车身整个吞掉（UNION 不产生几何）。

## 6. 车轮（4 独立闭壳）

| 项 | 值 |

| 轴距 | 2500（x=±1250） |

## 9. 已知边界

- 敞篷是"盲腔 + 座椅 + 头枕鼓包"，不是完整内饰（无仪表台/方向盘）。
- 风挡是框 + 平玻璃板，不是曲面夹层。
- 排气管是直管，不做消音器鼓包。
- 与出租车同场景时跑车 `location = (−6.5, 0, 0)`，**不 apply 变换进交付 FBX**。
