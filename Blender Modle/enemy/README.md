## 模型规格

- 单位：米，1 BU = 1 m；Z 向上；朝向 **-Y**（Unity/glTF 导出后为 -Z 前向）。
- 原点在双脚中心的地面处，脚底 z = 0。
- 分面（flat shading）低模，无细分、无贴图；全部靠**几何 + 材质槽**表达：
  - 红色甲壳 / 深灰裙边 / 中灰头部与大腿 / 橙色饰条 / 蓝色条纹 / 自发光琥珀面罩。
- 对象（均为独立件，方便在引擎里替换/换材质）：

| 对象 | 作用 |
|---|---|
| `GEO-crawler-hull` | 主体甲壳（RED/DARK 两材质槽） |
| `GEO-crawler-cowl` | 头部装甲块（布尔开出面罩凹槽） |
| `GEO-crawler-visor` | 自发光面罩条（AMBER，emission 4.0） |
| `DECAL-band-L/R` | 两侧橙色 Z 形饰条（贴合壳面，偏移 5 mm） |
| `DECAL-blue-1/2` | 甲壳顶部两道蓝色斜条（贴合壳面，偏移 6 mm） |
| `GEO-crawler-leg-FL/FR/BL/BR` | 四条腿，各含大腿(灰)/膝环(橙)/小腿(深灰)三段 |

## 已知偏差（如实记录）

1. **站姿偏高、腿偏长**：参考图的身板更低、腿更短更粗；模型为了对上整体投影高宽比
   做了 1.19 倍的统一竖向拉伸（`ZS`），腿因此显长。
2. **面罩偏窄**：参考图面罩两端沿头部侧面折过去（包裹式），当前是正面平直 + 末端后退，
   投影宽 263 px 对参考 334 px。要一致需按头部轮廓扫掠或拆成三段折面。
3. **侧饰条整体偏高约 60–90 px，且比参考窄**：壳面高度与相机仰角在单视图里强耦合，
   无法唯一反解；已通过多轮迭代压到当前偏差。
4. **甲壳分面更"圆"**：参考图只有很少的大面（硬棱分面），模型的环截面更密，显得圆润。
5. **蓝色斜条是 6–8 mm 厚的贴片**（贴合壳面），侧视时会看到一条发丝状边缘；这是有意的
   贴花做法，不是悬空。
6. **单视图固有多解**：背面、底面、另外两条腿的内侧、腹板都是合理推断，不是从图上量出来的。
7. 腿环橙带的投影 bbox 比参考大：参考量测只包含受光的橙色像素，模型量的是整段几何，
   两者口径不同，不能直接比。

## 引擎侧说明（Unity）

`export/crawler.glb` 已校验：glTF 2.0 二进制，11 个 mesh、6 个材质、**471 三角面**，
带 `KHR_materials_emissive_strength`（面罩自发光会被 Unity 的 glTF 导入器识别）。

- 导入后 Y 轴向上，模型高度约 1.55 m、长 2.2 m、宽 1.65 m（脚底在原点平面）。
- 材质是纯色 PBR（无贴图），如需换肤直接在 Unity 里替换材质或给材质加贴图即可；
  红/深灰在同一个 mesh（`GEO-crawler-hull`）上占两个材质槽，注意别把槽位顺序打乱。
- 想给腿做动画：四条腿是独立对象（`GEO-crawler-leg-*`），枢轴在各自髋部正上方，
  直接挂骨骼或按对象做旋转最省事。
