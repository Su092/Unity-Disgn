# 任务：单张箱庭 + 时间轴（4:00 精英 / 8:00 Boss）

- 状态：**完成**（2026-11-15）
- 依据：`docs/gameplay-spec.md` §2 §2.1 §3 §4 §7 §11
- 目标：把「6 区域串走廊 + 清区开门」的关卡制改成**一张 120×120 竞技场**，
  节奏改由存活时间驱动：4:00 首只精英，8:00 Boss 入场，击杀 Boss 才算通关。

## 为什么改

| 原设计的问题 | 具体表现 |
|--------------|----------|
| 6 段重复暖场 | 每区都要重新「进门 → 等第一波 → 清空」，真正高压只占全程 1/3 |
| 单局 25–35 分钟 | 配件系统的深度还没成型，玩家已经疲劳 |
| 威胁值靠「击杀 +0.4 / 秒 +1.2」 | 无限刷怪下会瞬间爆表；而且在惩罚「打得好」 |
| 清区降威胁是泄压阀 | 玩家可以靠拖时间呼吸，加压感被消解 |

## 关键设计选择

| 选择 | 理由 |
|------|------|
| 威胁**只**由时间决定 | 无限刷怪下「击杀加威胁」会爆表，且惩罚打得快，与「给停留定价」的意图相反 |
| 阶段决定「数量」，威胁决定「强度」 | 两个维度独立可调：想加压不加量抬系数，想加压不加硬提前解锁敌人种类 |
| 精英走独立时间轴，不挂钩威胁 | 让「什么时候遇到精英」可预期；同时它是中期唯一续航来源（击杀回血） |
| 方形场地而不是环形 | 四角与四边中点都能放高台，四条等长绕行路线；环形会让路线退化成同一个大圈 |
| Boss 入场后普通刷怪**降档不清场** | 清场会让 Boss 战变成空场单挑；降档（18→8 并发）保留压迫但不抢注意力 |
| 柱子只在 Boss 出场时生成 | 单图没有「Boss 区」，常驻柱子会被当掩体；破坏后玩家会以为地图坏了 |
| 精英碰撞体随视觉同步放大 | 只改视觉会造成「看得见打不中」，实机里极难定位 |

## 过程中修掉的真实缺陷

| # | 问题 | 现象 | 修法 |
|---|------|------|------|
| 1 | `PresetCases.cs` 引用不存在的 `PresetStore` | 整个断言工程**编译不过**（`CS0246` ×12），`-Task tests` 必然红 | 在 `.csproj` 显式 `Exclude`，并注明实现 `PresetStore` 后去掉 |
| 2 | `RunTelemetry` 里 `struct Mark` 与 `void Mark(...)` 同名 | `CS0102` 重复定义 | 结构体改名 `TimelineMark` |
| 3 | 新增遥测方法写成 private | `CS0122` 跨类不可见 | 改 `public` |
| 4 | `IReadOnlyList<Enemy>` 没有 `Exists` | `CS1061` | 显式遍历的 `HasElite` 辅助方法 |
| 5 | 用 PowerShell `Set-Content` 改写 `.cs` | **整个文件的中文全部乱码**，`CS1010 常量中有换行` ×数百 | 从 git 恢复后只用 `StrReplace` 编辑 |
| 6 | `check.ps1` 传 `-projectPath` 未加引号 | 路径含空格时报 `Couldn't set project path to: .../unity/F:/Unity` | 直接 `Start-Process` 传加引号的参数（脚本本身仍需修，见下） |
| 7 | 自检里 `SeekTo` 回拨共用实例 | 「4:00 威胁 50」实测 75.21（实例已被拨到 361s） | 威胁断言改用独立实例 |
| 8 | 精英放大同时乘了 `transform.localScale` 与 `CharacterController` | 实际体积是 **1.35² = 1.82 倍**（`CharacterController` 尺寸随 transform 缩放自动放大），近战范围远超视觉 | 只放大 `Body` 子物体与碰撞体，`transform.localScale` 保持 1 |
