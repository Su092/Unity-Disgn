# 任务 04 · 美术资产管线（APIMart 参考图 → Blender → Unity）

- 依据：`docs/art-style.md`、`.cursor/rules/apimart-image.mdc`、`.cursor/skills/blender-asset-pipeline/`

## 目标

把灰盒模型换成**有辨识度的低模资产**，并让地面/墙面用真实平铺贴图。
纪律：**素材可以缺，游戏不能崩**——任何一件缺失都回退到占位体。

## 管线（固定顺序）

```
① APIMart 出参考图（1k）      →  Art/Refs/*.png          12 张
② 按参考图写 bpy 脚本建模      →  Art/Models/*.fbx         12 件
③ 尺寸门 + 装配门             →  blender_s_build_assets.py 内置
④ 契约门（尺寸/单位/命名/落地）  →  tools/blender-gate.ps1
⑤ 预览渲染 + 空白检测          →  blender_s_preview.py
⑥ 复制进 Resources            →  Resources/Models,Textures
⑦ Unity 接入（SAssets）        →  缺失自动回退
```

## 内置的两道自检门（脚本里，不依赖外部工具）

| 门 | 判据 | 为什么必须有 |
|----|------|--------------|
| **尺寸门** | 模型高度必须落在设计范围 ±20% | 防「缩放系数写错导致所有件只有一半大」——这类错肉眼很难发现 |
| **装配门** | 每件必须与至少一件其他部件相交 | 防「部件悬空漂浮」——低模最常见的观感缺陷 |

实测抓到 5 个真问题：爬行者高度 0.80（差 5cm）、喷吐者双脚悬空、
单发枪弹匣悬空、无人机太扁（0.25m）、Boss 太小（2.64m）。

## 关键坑（都是实测踩出来的）

| 坑 | 现象 | 正解 |
|----|------|------|
| `primitive_cube_add(size=1.0)` 后再乘 0.5 | **所有盒体只有标称尺寸的一半**，部件之间出现缝隙 | 缩放系数直接用 `size[k]`，不要乘 0.5 |
| emission 强度过高 | 红色渲染成粉色、琥珀变成米白 | emission ≤1.0，真正的发光件单独设 1.2–1.4 |
| 预览相机只取 `children_recursive` | 对象自身就是 Mesh 时目标集为空 → 渲染出纯背景 | 先判断 `ob.type == "MESH"` 再取子孙 |
| 只靠「渲染成功」判断 | 相机没对准也渲染成功，图片是纯灰 | 采样像素算亮度方差，<0.0008 判空白 |
| 每次 `Instantiate` 后 `go.name = modelName` | 对象名被 Unity 改写，用名字找模型永远失败 | 用 `sharedMesh.name` 判「是否非 primitive 网格」 |
| `SpawnFit` 一律按高度归一 | 枪械躺倒后长边在 X 轴，被缩得极短 | 枪械传 `groundAlign:false`，改按最长边归一 |
| 强行统一材质 | 抹掉参考图的分色设计 | 模型默认 `keepMaterials=true`，只在缺件回退时染色 |
