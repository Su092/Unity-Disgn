# 数值校准日志 — S

> 每次校准记三件事：**旧值 → 新值 → 依据（实测数据）**。
> 不写「感觉弱了」这类依据，只写可复现的测量结果。

## 2026-11-12 首轮校准

### 方法

新增 `tools/loadout-tests` 的两个基准入口：

```powershell
cd "<GAME:S>\tools\loadout-tests"
dotnet run -c Release -- -bench     # DPS 基准 + 经验曲线
```

`DpsBench` 用**蒙特卡洛弹道模拟**算实际命中率，不用纸面公式：

- 目标：半径 0.5m 的球（敌人躯干近似），20m 距离
- 每颗弹丸在散射锥内均匀取偏移，检查轨迹与目标的最近距离
- 存在时间到期未命中 = 未命中
- 榴弹走抛射（含重力）

**为什么必须模拟**：霰粒散射 +3°、分裂后每颗再 +2°，纸面 DPS 会高估一个量级。
实测「分裂+霰粒」链：纸面 85.0 → 实测 18.8（命中率仅 22.1%）。

### 校准过程中的两个测量 bug

| # | bug | 现象 | 修正 |
|---|-----|------|------|
| 1 | 弹道采样按「生命周期均匀分 48 步」 | 单发枪（140m/s × 1.2s = 168m 射程）每步跨 3.5m，而目标球只 1m → **命中率算成 0%** | 改为按距离自适应步长（5cm） |
| 2 | 多目标场景朝正前方盲射、目标随机散布 | 命中率近 0，看似「武器全废」 | 改为瞄准最近目标（真实玩家会瞄准） |

第 1 个 bug 特别值得记：它让「单发枪 DPS = 0」，如果不是我怀疑测量方法而是直接改数值，
会把一把正常的枪改成怪物。

### `m_blast` 单独说明

初版是「溅射 +1.6m / 伤害 ×1.25」。实测发现它让**单发枪群伤从 68 涨到 161（2.4 倍）**，
而榴弹枪本职群伤是 170 —— 一个史诗配件几乎抹平了武器定位差异。

降为「+1.4 / ×1.00」后：单发枪群伤 121.8，榴弹枪 170，层级恢复。
它仍然是史诗（溅射对单体链是质变），但不再能替代榴弹枪。

### 群伤场景（5 敌，6×3m 区域）

| 档位 | 连发 | 榴弹 | 单发 |
|------|------|------|------|
| 浅构筑 | 120.6 | **191.5** | 68.2 |
| 深构筑 | 183.0 | 170.0 | **274.4**（爆裂流） |

**设计意图达成**：
- 榴弹枪**天然群伤**（不依赖配件）
- 单发枪要吃到 `m_blast`（史诗）才有群伤能力，且是爆发型
- 连发枪两者居中，靠射速与轮转多样性

### 经验曲线

不改。实测一局经验投放 ≈2286 XP → 到达 **LV 14**、16 次三选一，
落在 `gameplay-spec.md` §11 设计的 12–15 级 / 14–16 次区间内。

明细：5 个战斗区共 1884 XP（含 6 区 Boss 场的 3 次三选一）。

### 散射代价（已验证有效）

| 链 | 纸面 DPS | 实测 DPS | 命中率 |
|----|----------|----------|--------|
| `[制式弹]` | 60.3 | 60.4 | 100% |
| `[量子分裂, 校准套件, 霰粒]` | 85.0 | 18.8 | **22.1%** |

散射让「分裂霰粒流」在 20m 只发挥 22% 的纸面威力。
这说明散射参数确实构成真实取舍：近战喷子 vs 远程精准。

## 2026-11-15 单图时间轴改造（结构变更，非数值校准）

本轮改的是**节奏结构**，不是武器数值。三枪 DPS 一分未动（极差仍是 1.21×）。

### 改了什么

| 项 | 旧 | 新 | 依据 |
|----|----|----|------|
| 场地 | 6 区 ×（34×44）串联 | **1 张 120×120** | 6 段重复暖场，真正高压只占 1/3 |
| 节奏来源 | 区域推进 | **存活时间**（`RunDirector`） | 让「还剩多久」可被玩家计算 |
| 威胁 | 秒 +1.2 / 击杀 +0.4，清区 −25 | `100 × t / 480`，无泄压阀 | 无限刷怪下击杀项会爆表，且惩罚快速清场 |
| 威胁满 | 无明确终点 | **8:00 与 Boss 对齐** | 「变到最硬」与「Boss 出场」应是同一件事 |
| 敌HP缩放 | `1 + 0.004 × threat` | `1 + 0.008 × threat` | 无清区泄压阀，原斜率在 8 分钟只让敌人硬 40%，终局检验不足 |
| 敌伤缩放 | `1 + 0.0025 × threat` | `1 + 0.004 × threat` | 同上 |
| 精英 | 威胁 ≥35 的最后一波 | **4:00 / 5:30 / 7:00 共 3 只** | 与威胁脱钩，让遇见精英可预期 |
| 经验来源 | 击杀 + 清区 15% | **只有击杀** | 清场效率应直接等于构筑速度 |
| 单局时长 | 25–35 分钟 | **9–12 分钟** | 配件深度要在一次坐下里看到成效 |

### 经验预算重算

| 项 | 旧（分区制） | 新（单图） |
|----|--------------|------------|
| 普通击杀 | ≈1190 | ≈2200（8 分钟无限刷怪，按可清速度估） |
| 清区奖励 | ≈180 | **0**（取消） |
| 精英 | ≈240 | ≈240（3 只 × 48） |
| Boss 战杂兵 | 0 | ≈220 |
| **合计** | ≈1610 → LV 12–13 | **≈2660 → LV 15 附近** |

→ 落在「13–17 级 / 16–19 次三选一」区间内（`gameplay-spec.md` §11）。

**`XpBench` 已同步**：旧的按区域波次循环已换成按时间轴阶段 × 玩家可清速度估算，
判据从「12–15 级」改为「13–17 级」。

### 没有调的

- 三枪 `damageMul` / `fireInterval` / `magSize`：全部保持首轮校准结果
- `m_blast` 的 `splashAdd=1.4` / `damageMul=1.00`：保持
- 等级曲线 `need(L) = 2L² + 5L + 8`：保持

**为什么不一起调**：DPS 与经验是在「旧节奏下」校准的，但它们是**相对关系**
（三把枪彼此均衡、曲线决定升级频率），与关卡分段方式无关。
先定结构再动数值，否则两个变量同时变，实测数据无法归因。
