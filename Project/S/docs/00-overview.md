## 与工程的关系

- **文档只在枢纽**。工程内 `Assets/` 只放代码与运行时资源，不放过程文档。
- 唯一权威数值是建工程后的 `unity/Assets/Resources/Data/sdata.json`；
  `gameplay-spec.md` 与 `loadout-spec.md` 是它的**人读镜像**。改数值必须两边一起改。
- 工程根 `README.md`（建工程后）面向「打开工程就能跑」的人，只保留运行/验证/目录速览。

## 书写约定

- 先文档、再拆解、再实现；无文档依据不直接开做大块内容。
- 改设计时**整文件覆盖**对应 `docs/*.md`，禁止在文末叠「补充说明 / 另见」链。
- 实现任务写到 `../breakdown/`，不在 `docs/` 里堆待办清单。
- 数值一律写「当前值 + 出处字段名 / 表内 ID」，便于回查 `sdata.json`。
- 阶段性结论写 `../memory/`，不写进设计文档。
- 表格里的数值都是**初版待校准值**；校准结论回写进对应文档的表，不另开文件。

## 术语表（全文档统一，不要再造同义词）

| 术语 | 含义 |
|------|------|
| **施法链** chain | 一个配件位内按顺序排列的配件序列；开枪时整条链解析成一组投射物 |
| **子弹配件** Bullet | 链中的投射物本体，定义伤害/弹药/散射/存在时间/暴击 |
| **衍生配件** Modifier | 链中的修正件，作用于子弹配件的属性或行为 |
| **作用域** scope | 衍生配件的生效范围：`全场`（Whole）/ `仅后方`（After） |
| **投射物** projectile | 结算器输出的运行时对象（一颗弹丸一个），弹丸数为 1 的子弹配件产出 1 个 |
| **槽位** slot | 配件位。枪有 `slotCount` 个，开枪时按轮转取用 |
| **施法** cast | 一次开枪 = 解析一个槽位的链 = 消耗一次弹药 |
| **弹药** ammo | 枪的弹药点，`magSize` 为上限；每次施法按该槽内子弹配件的 `ammo` 之和扣除 |
| **有效伤害** | 经过暴击期望与倍率后的单发期望伤害，UI 与验收都用它 |
| **箱庭** | 本作的大地图单位：连通多区域、可持续刷怪、有目标的半开放关卡 |
