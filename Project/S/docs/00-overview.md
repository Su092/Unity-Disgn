## 与工程的关系

- **文档只在枢纽**。工程内 `Assets/` 只放代码与运行时资源，不放过程文档。
- 唯一权威数值是 `unity/Assets/_Game/Res/Cfg/*.tsv`（11 张三行表头，经联接即 `<GAME:S>\Assets\_Game\Res\Cfg\`）；
  `gameplay-spec.md` 与 `loadout-spec.md` 是它的**人读镜像**。改数值必须两边一起改。
- 工程根 `README.md` 面向「打开工程就能跑」的人，只保留运行/验证/目录速览。
- 枢纽 `unity/` 是到 `<GAME:S>` 的目录联接：读工程一律走 `unity/...` 相对路径，不要写死盘符。
- 本目录**只放 markdown**。图片、参考图、截图副本一律放工程的 `_Inbox/` 或 `Shots/`。

## 书写约定

- 先文档、再拆解、再实现；无文档依据不直接开做大块内容。
- 改设计时**整文件覆盖**对应 `docs/*.md`，禁止在文末叠「补充说明 / 另见」链。
- 实现任务写到 `../breakdown/`，不在 `docs/` 里堆待办清单。
- 数值一律写「当前值 + 出处表名 / 字段名 / 行 ID」，便于回查 `Cfg/*.tsv`。
- 阶段性结论写 `../memory/`，不写进设计文档。
- 表格里的数值都是**初版待校准值**；校准结论回写进对应文档的表，不另开文件。

## 术语表（全文档统一，不要再造同义词）

| 术语 | 含义 |
|------|------|
| **槽位** slot | 配件位。枪有 `slotCount` 个，一格放**一件** |
| **作用域** scope | 物理格位范围，共 10 种，详见 loadout-spec.md；Next/Prev 仅后一格/前一格 |
| **子弹配件** Bullet | 投射物本体，定义伤害/耗弹/散射/存在时间/暴击，共 17 件 |
| **衍生配件** Modifier | 弹丸向 25 件 + 枪械向 9 件，共 34 件 |
| **读取式扫描** scan | 一次射击的结算方式：从指针位置起**顺时针逐格扫描**，读到什么就打什么，一次性解析出全部投射物。旧版「链式按时间逐项触发」**已作废** |
| **读取** read | 扫描读到子弹，消耗一次读取预算；衍生件按物理范围吸附，不单独读取 |
| **被动** passive | 子弹向衍生件按物理作用域吸附，包含 Next；枪械属性件在 ResolveGun 汇总 |
| **投射物** projectile | 结算器输出的运行时对象（一颗弹丸一个），共 7 种形态：`Proj` / `Beam` / `Mine` / `Field` / `Chain` / `Saw` / `Hole` |
| **施法** cast | 一次开枪 = 扫一轮 = 扣一次弹药。`castCount` 决定这一轮读几发（霰弹枪 = 2） |
| **指针** cursor | 下一次施法的起始格。打完往前推到「最后一次读取之后」，换弹**不重置** |
| **弹药** ammo | 枪的弹药点，`magSize` 为上限；每次施法扣 Σ(读到格子的 `cost`) + Σ(吸附的被动件 `cost`) |
| **有效伤害** | 经过暴击期望与倍率后的单发期望伤害，UI 与验收都用它 |
| **触发弹** trigger | 带 `Hit` / `Timer` / `Expire` 载荷的子弹，命中/定时/消散时递归施放「下一个子弹」，上限 6 代 |
| **竞技场** arena | 本作唯一场地单位：一张 100×100 m 连续场地，无分区、无门、不加载 |
| **时间轴** timeline | 驱动本作节奏的唯一机制：按存活秒数切换刷怪阶段，5:00 首只精英，10:00 Boss 入场 |
| **精英** elite | 5:00 起每 90 s 入场一只的强化敌人（本局共 4 只），击杀回复玩家生命 |
| **威胁值** threat | 0–100 的难度标尺，**只由存活时间决定**（`100 × t / 600`），缩放敌人 HP 与伤害 |
