- **14 木琴棘龙**：四次逐板落音，敲击间隔0.9s，每次敲击取玩家当前位置，音符先悬停0.5s再用0.3s下落。四栏施放固定朝向，等权4–8个时点、0.8s间隔，每时点独立20%双击，双击不同栏、内部0.12s且只算一组；双栏在首击前共同高亮。宽2.2m、最长18m、高3.6m的推进判定覆盖正常跳跃，实体掩体可挡。
- **21 风笛野猪**：1.2s蓄风，最后0.4s锁向；10m/s、最长12m冲锋，撞障碍后有撞击/2s眩晕/起身；近身侧向0.8s预警后放风，结束恢复蓄气。
- **16 八音盒舞姬**：完整圆弧预告、沿实际地面旋进，遇障停止；半血后0.9s预警，沿真正走过的轨迹倒带。三排带宽缺口的慢弹；1.5s谢幕窗口，仅命中滚筒 WeakPoint 代理受到1.5倍伤害。倒带后的谢幕2s。
- **29 游吟指挥家**：舞台闪现、随机一只精英召唤、二楼栏杆音符枪和半血终章三轮合奏。召唤物仅最大生命降为同进度正常精英35%，伤害/速度/节奏仍与正常精英一致；召唤期间Boss减伤80%，可继续召枪。
- **音符枪**：由实际栏杆模块提取挂点，至多3把，普通血量为Boss最大生命5%。0.8s红线，最后0.2s锁向，随后快速音符弹；骨骼炮管跟随目标。可被现有投射物、光束、范围攻击等破坏，不能被吸引效果拉离栏杆；无击杀/经验农场奖励。破坏取消排队攻击与激光并释放已交付碎片。
- **终章**：开招仅补一次至3把，先将上限设为10%并回满。前两轮各合计随机3–5发，先随机分配给当前枪再错峰执行；被毁枪丢弃其排队攻击，不补回。第三轮存活枪同步0.8s预警，4s连续跟踪激光，瞄准点速度为标准步行速度30%，0.25s伤害间隔。结束按剩余血量比例恢复5%上限。
- **聚光灯**：精英与Boss均有暖金光束/灯光/地面光斑。29召唤后转给精英，死亡回归；普通召枪不改变焦点。召唤和终章保护重叠仍为80%，两种来源都结束才恢复正常伤害。
- 精英两个外观变体共用本体逻辑，不额外加能力。普通03改为较快近身追击，11使用悬空模型追近并远程攻击；不再让其继续承担旧轰炸者自爆或零速固定炮台的表现。

## 集成与生命周期
`MusicCombatRules` 保存确定性配额、双击、分配、血量换算等规则；`MusicEliteBrain`、`MusicBossBrain`、`MusicNoteGun` 处理释放流程。
`MusicHazard` 用真实扫掠与地图遮挡处理音符/波/弹道，地面攻击隔离上下楼层。普通警戒光与红色攻击光区分；警戒纹理不决定实际命中，几何边界与伤害范围一致。
沿用现有伤害、弹丸、经验与动画入口。新Boss不再执行旧能量柱护盾/杂兵召唤/全屏冲击波。修复Boss贴地查询把邻近敌人胶囊误认为地面的问题。循环动作保持正常动画速度，不再把整个循环拉长到技能总时长。
暂停使用缩放时间，死亡、结算、场景重开会清理攻击及召唤；精英死亡取消未完成连击，Boss死亡清理其全部炮台与召唤物。
