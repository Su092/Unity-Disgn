# 配件规则与数值 — S

当前实现基线：6 把枪、17 种子弹、34 种衍生配件（弹丸向 25 + 枪械向 9），共 51 种配件、10 种作用域。配置源为 `unity/Assets/_Game/Res/Cfg/*.tsv`；表格为 Lv.1 配置镜像，空值按数据模型默认值解释。

## 1. 容器与实例

一格一件，枪械槽数来自 Gun.tsv。枪拥有独立布局与轮转指针，切枪保留各自装配。每个 ChainItem 是独立实例，等级默认为 1，最高 5；共享 BulletDef / ModifierDef 不得因合成而修改。

## 2. 物理作用域

| 枚举 | 玩家文案 | 覆盖相对槽位 |
|---|---|---|
| Next | 后一格 | +1 |
| Prev | 前一格 | −1 |
| Adj | 前后各一格 | −1、+1 |
| N2 | 后两格 | +1、+2 |
| N3 | 后三格 | +1、+2、+3 |
| P2 | 前两格 | −2、−1 |
| P3 | 前三格 | −3、−2、−1 |
| Adj2 | 前后各两格 | −2、−1、+1、+2 |
| Skip | 隔一格 | −2、+2 |
| All | 全枪 | 除自身外全部槽位 |

范围按物理槽位编号计算，越界截断，不绕回、不跨空槽寻找子弹。空槽或其他衍生件可以被范围覆盖，但不传递效果，也不算实际子弹目标。枪械属性件在全枪结算；子弹向配件只作用于范围内的子弹。

## 3. 结算流程

1. ResolveGun 先汇总全枪属性；弹匣倍率以浮点累乘，最后取整，最少 1 发。
2. 从轮转指针开始扫描；跳过空槽和全部衍生件，只读取子弹。扫描可环绕，最多扫描 64 格。
3. 对读取到的子弹，按物理范围收集 EffectiveMod，作用于 EffectiveBullet 生成的描述符。后/前一格不随扫描方向改变。
4. 子弹自身 cost 加所有实际吸附配件的 cost，单次子弹耗弹最低 0；没有目标的配件不收费。节能回路通过负 cost 减耗，升级后保持 cost 与节能等级一致。
5. 每颗子弹计入自身及吸附配件的 delay；最终击发间隔为 max(0.03, (枪基础间隔 + 本次 delay 总和) × 枪间隔倍率)。
6. 双重/三重施放由物理紧邻的后一格子弹触发，增加读取预算；重复绕回同一目标不无限追加。它们不是全枪属性件。
7. 指针推进至最后读取之后；换弹不重置。HUD、安装预览和实战共用 ResolveCast。

子弹伤害/体积/速度等乘法修正逐件施加，穿透/反弹等加法修正逐件累加。暴击上限 100%，减速上限 85%，单份描述符弹丸数最多 24。枪的 SpreadMul 会作用于子弹散射；SpreadBase 当前未额外叠到弹丸散射中。

爆裂对已有爆炸扩大半径；无爆炸时用 explodeRBase 建立半径，爆炸伤害由当前伤害 × explodeDmgFromDmg + explodeDmgFlat 计算。准确公式以 Loadout.ApplyMod 为准。

触发弹的 Hit / Timer / Expire 载荷使用 NextBulletCell 循环寻找后续子弹，递归最多 6 代。这是载荷解析，不是 Next 作用域；不要把两者混用。

## 7. 同种同级合成

同种同级的两个配件，通过拖放合为一个高一级配件，最高 Lv.5。支持子弹、弹丸衍生和枪械属性配件，支持背包互合、枪槽互合及二者之间双向合成。成品留在目标位置，来源位置清空；不需要第三个空格，满背包也可合成。

不同配件沿用安装/交换操作。同种不同级、满级或自身拖放不合成、不消耗、不自动卸下。拖动悬停时预览合成结果，卡片和详情显示等级，枪械数值立即重算。

- 子弹伤害、爆炸伤害及燃烧：Lv.1～5 为基础值的 1 / 1.5 / 2 / 2.5 / 3 倍。
- 衍生配件的正向连续加成使用相同强度系数；穿透、反弹、额外读取等整数收益每级增加 1。
- 换弹、射击间隔和散布缩减按原倍率的强度次幂计算。
- 原有正耗弹、负面伤害/速度/散射和弹匣代价不会因等级加重。节能收益随等级提升。
- 减速最高 85%、暴击最高 100%、单发数量最高 24，保留性能与数值边界。
- 升级不改变作用域、稀有度、子弹形态及触发方式，不修改共享配置或其他同名实例。
- 史诗配件允许跨轮重复抽取，支持合成；同一次三选一仍不重复。

## 8. 装配与范围预览

- 点击配件保留选中状态；悬停显示当前效果范围；拖动时显示落点后的范围和结算变化。
- 金色标出来源，蓝色标出覆盖槽位，绿色标出真正受影响的子弹。不能将空槽高亮解释成已生效。
- 预览使用槽位副本；枪内移动会先移走来源，交换保留原目标，合成预览先消耗来源再显示高一级成品，不修改实际布局。
- 同种同级拖放合成；不同种类沿用安装/交换；同种不同级、满级或自身拖放保持原物品，不触发自动卸下。
- 卡片显示等级，详情按等级展示实际效果，tooltip 缓存按 ID 与等级区分。
- 没有子弹目标的投射物配件给出提示；空枪允许关闭背包，开火时返回 no-bullet。
- 右键快速装卸，拖到空白卸回背包；装配后立即重算枪属性。

## 9. 抽取与回收

升级配件池为全部 51 件；Common / Rare / Epic 权重为 60 / 30 / 10（RarityWeight.tsv）。
同一次三选一不重复 ID，史诗允许跨轮重复以支持合成，UsedEpics 仅作记录。
分解获得经验普通 3 / 稀有 6 / 史诗 9，沿用 RunState.Salvage。
传入已持有枪集合时，每轮有 10% 概率加入最多一把未持有枪；纯配件旧接口仍只抽配件。
