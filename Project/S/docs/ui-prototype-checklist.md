# 需要提供原型图的界面清单

按当前实际实现整理，供下一轮音律主题UI重做使用。HUD总布局已有原型并已实施，本轮不需要重新画。建议先提供6组页面/弹层原型；局外解锁与音量设置可以并入其中，无需强制拆成额外页面。

原型可以沿用之前的黑白线框加红字说明。首选1920×1080画布，只需要明确布局、信息层级、状态和跳转；按钮美术、九宫格、切图、素材命名由后续制作处理。

## 一、优先出图：直接影响局内构筑

| 编号/优先级 | 界面 | 当前入口与行为 | 原型必须包含 | 建议提供的状态图 |
|---|---|---|---|---|
| UI-01 / P0 | 背包与乐器改装 | Tab或HUD主乐器入口；打开后暂停；可切换查看持有的乐器 | 主/副乐器切换区、乐器名称与核心数值、槽位排布及物理序号、配件背包与容量、固定详情区、安装后数值变化、关闭/操作说明位置 | ①正常/选中配件；②拖拽安装+影响范围；③相同配件合成预览；满包错误可在旁标注 |
| UI-02 / P0 | 升级三选一 | 经验拾取升级弹出；点击领取；可出现配件或乐器；连续升级排队处理 | 标题、3张候选卡、图标/名称/类别/稀有度/效果/耗弹等必要数值、详情展示位置、领取入口 | ①三张普通配件；②其中一张为乐器；③容量不足、转去整理背包后返回本次选择 |

### UI-01需要明确的特殊状态

- 持有上限、槽位数、背包容量以配置为准，布局需适配当前两把乐器与6/8/10/12槽；背包当前44格，超出可视区域的滚动方向要画清楚。
- 作用域按物理槽位：前一格/后一格、相邻、前后多格、隔格、全体等。展示“配件所在位置”“覆盖位置”“实际生效子弹”三种含义，颜色和图例位置由原型定。
- 选中、悬停和拖拽不能混为一个状态；固定详情区至少包含名称、类型、稀有度、等级、作用域、主要数值与预览变化。
- 合成沿用“同种同级的两个配件，任意一个拖到另一个上，结果留在目标位置”，最高Lv.5。不需要另画合成工作台；画可合成提示、结果等级和不可合成提示的位置即可。
- 安装、交换、右键卸下与满包反馈要有位置。暂不把代码注释中出现的“分解框”当作已实现按钮：现有普通交互没有完整分解入口；若要增加，需在原型上标为新增需求。

### UI-02需要明确的特殊状态

- 获得新乐器时：未达持有上限则领取并装备；已满则替换当前乐器，原配件收回背包。候选卡要明确显示替换对象。
- 背包不足不能丢失本轮奖励；现在支持先整理再返回。需决定提醒放卡片内、页底还是独立小提示。
- 当前没有刷新、跳过、锁定、付费重抽和数字快捷选择。若原型要出现这些按钮，请标“新增玩法”，不要默认为已有功能。

## 五、当前无需你重画的内容

- HUD主布局、准心/换弹旋转标、弹药弧、玩家血量/经验、小地图、Boss条、暂停入口：沿用已有图和确认结果。
- 受伤屏幕边缘：本轮恢复现有红色渐变闪边，不需要新原型；没有增加持续低血量呼吸效果。
- 右下道具栏：仍为占位，未确定使用规则前不要求道具功能页。
- 暂无独立完整图鉴、商店、地图选择、角色选择、新手教程等已实现界面，不把它们列为本轮必交原型。若未来准备加入，可再单列。
- 关卡内的落雷范围、音符枪红线、精英/Boss聚光灯属于战斗提示与特效，不是整页UI原型。

## 六、每份原型只需附这些说明

1. 页面编号和状态名：例如UI-01_拖拽安装。
2. 哪些信息一直显示，哪些随选中/悬停/拖拽变化。
3. 按钮点击后去哪里；关闭后回到哪里；有无暂停。
4. 容量不足、长名称、最大槽位、最高配件等级等拥挤状态如何摆放。
5. 若涉及新增功能，请单独标注“新增”，与已有功能换布局区分。

推荐交付顺序：UI-01背包 → UI-02三选一 → UI-03开局选乐器 → UI-04首页 → UI-05暂停 → UI-06结算。第一批先给前三组即可开始制作。
