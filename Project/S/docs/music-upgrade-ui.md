## 二倍速度与折角修复（2026-11-20）
用户要求保持曲线，速度提高一倍。进场2.6→1.3秒、退场2.2→1.1秒。原始素材五条线平滑；旧97点像素覆盖重心算法受抗锯齿/线宽影响，中心线身体段RMS偏差1.29px、最大3.78px，造成二次变形折角。改为五条笔画等权亚像素中心、平滑拟合与1025点三次插值；源中心拟合RMS0.067px、最大0.461px。保持原素材与固定路线，曲线采样落点/法向使用解析计算，网格分段提高到512。无需调用APIMart。
