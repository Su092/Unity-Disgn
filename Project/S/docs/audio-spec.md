# 音频规范 — S

> 初版**尚未实装任何音效**（见 `technical-design.md` §7 技术债）。本文件是可执行的规格，
> 拆解 P3 按此实现，避免到时候临时拍脑袋。

## 1. 为什么 FPS 的音频比画面更关键

FPS 里玩家 80% 的威胁感知来自声音：背后有没有爬行者、盾卫从哪边来、自己还剩几发。
本作的配件系统还会改变射击音色（射速 ×1.22、分裂 ×3、追踪），声音必须**跟着配件变**，
否则玩家装完配件「听不出变强了」，构筑反馈就断了一半。

## 2. 频段分配（避免混浊）

| 层 | 频段 | 主导内容 |
|----|------|----------|
| 低频（20–120 Hz） | 冲击 | 爆炸、榴弹发射、Boss 落地 |
| 中低（120–400 Hz） | 重量 | 枪身后坐、脚步、装填 |
| 中（400–2k Hz） | 信息 | 敌人靠近、命中反馈、UI 提示 |
| 中高（2k–6k Hz） | 清晰度 | 暴击、子弹擦过、拾取 |
| 高频（6k+ Hz） | 空气感 | 弹壳、玻璃、能量充能 |

**纪律**：同一时刻最多 2 层占用 400–2k Hz（信息层）。超过会盖住「敌人接近」提示。

## 3. 枪械音轨分层（按配件动态组合）

一把枪的开火音 = 三轨叠加，各轨独立随机化音高 ±8%：

| 轨 | 触发条件 | 说明 |
|----|----------|------|
| `body` 本体 | 每次施法 | 枪身机械声，随 `fireInterval` 变换（快射用短促版） |
| `shot` 弹药 | 每个子弹配件 | 制式弹=清脆、重芯弹=低沉、霰粒=散响、光矛=能量啸叫 |
| `tail` 收尾 | 每次施法 | 尾音时长随 `lifetime` 缩放（延时引信会明显拖长） |

**配件改音的规则**：
- 弹速 `speedMul > 1.3` → `shot` 轨音高 +2 半音（听起来更快）。
- 分裂 `splitCount > 1` → 追加一层 30ms 延迟的弱化副本（模拟多发）。
- 追踪 `homingRate > 0` → 追加持续 0.2s 的轻微嗡鸣。
- 溅射 `splashRadius > 0` → 命中时叠加低频爆音。

## 4. 事件音与优先级

| 优先级 | 事件 | 处理 |
|--------|------|------|
| 1（最高） | 玩家受伤 | 永不打断，且压低其他层 6 dB |
| 2 | 敌人接近（6 m 内） | 短促环境音，1.2 s 冷却 |
| 3 | 开枪 | 每次必发，但同类限流 20 次/秒 |
| 4 | 命中 | 命中敌人=短脆；打墙=闷响 |
| 5 | 拾取/升级 | 可被丢弃 |
| 6 | UI 悬停/点击 | 最低，可被丢弃 |

**限流**：全局同时播放 ≤16 个 `AudioSource`，超出按优先级丢弃。连发枪 9 发/秒 × 3 轨 = 27 次/秒，
必须靠「同类合并 + 音高随机」而不是全部播放。

## 5. 音乐

| 场景 | 处理 |
|------|------|
| 探索（威胁 <35） | 低音垫 + 稀疏工业节拍，无旋律 |
| 战斗（威胁 35–65） | 加入 4/4 打击层，节奏 100 BPM |
| 高压（威胁 >65） | 加失真低音 + 心跳，节奏 128 BPM |
| Boss | 独立曲目，三阶段切换层 |
| 背包（暂停） | 音乐降低 8 dB 但**不停**（保持紧张感） |

**不要**在背包打开时静音：玩家需要「时间在流逝」的听觉压力（即使实际暂停）。

## 6. 实现约定

| 项 | 决定 |
|----|------|
| 音频中间件 | 不用 FMOD/Wwise。Unity 原生 `AudioSource` |
| 程序化生成 | 初版可用代码合成（噪声 + 包络）替代素材，先验证节奏 |
| 3D 空间化 | 世界音全部 `spatialBlend = 1`，UI 音 `0` |
| 混音 | 分组 `Master / SFX / Music / UI`，暴露音量设置 |

## 7. 验收判据

1. 闭眼听 10 秒，能说出「有敌人在左边接近」。
2. 装上 `高速击发` 后，开枪听感明显更急促（不需要看 UI 秒数）。
3. 连发枪持续开火 5 秒，无音频爆音、无卡顿、无削波。
4. 打开背包后音乐仍在，且能听出「世界没停」。
