# 视觉规范 — S「低多边形工业科幻」

## 1. 定位

**风格关键词**：厚块体、硬边、哑光金属、高对比色块、极少纹理、强轮廓。

不是写实、不是手绘描边、不是像素。目标是：**一眼能读出距离、体积与敌方类型**，同时资产制作成本可控（Blender 低模 + 纯色材质即可量产）。

| 项 | 决定 |
|----|------|
| 多边形量级 | 单件 300–2500 三角面（敌人 ≤1200，掩体 ≤300，枪 ≤2500） |
| 贴图 | **默认不用贴图**，用材质纯色 + 顶点色；需要细节时用 256² 平铺无接缝图 |
| 描边 | 不用全屏描边。用「暗色底座 + 亮色顶面」两段材质制造硬边感 |
| 光照 | 单方向光 + 平面环境光；不用烘焙（迭代速度优先） |
| 后处理 | 轻：Bloom + 轻微 Vignette + 色彩分级（冷色阴影、暖色高光） |

## 2. 配色

### 2.1 世界

| 用途 | 色值 | 说明 |
|------|------|------|
| 地面 | `#33383F` | 中性深灰，让子弹和敌人跳出来 |
| 掩体/结构 | `#4C525C` | 比地面亮一档，区分高度 |
| 边界墙 | `#292D34` | 最暗，形成视觉边界 |
| 高亮装饰带 | `#E8A33D` | 琥珀色，标记可交互/危险 |
| 熔渣/危险液体 | `#D2502B` | 自发光 0.6 |

### 2.2 敌人（**唯一色相编码，不要挪用**）

| 类型 | 主色 | 理由 |
|------|------|------|
| 爬行者 `Crawler` | `#E0474C` 红 | 近战冲刺＝紧迫 |
| 喷吐者 `Spitter` | `#9ED940` 黄绿 | 远程酸液 |
| 盾卫 `Shield` | `#4D85F2` 蓝 | 装甲＝冷硬 |
| 无人机 `Drone` | `#EB9E38` 橙 | 空中单位 |
| Boss 核心 | `#B45CE0` 紫 | 唯一紫色，最高威胁 |

**纪律**：玩家视野里出现紫色 ⇒ 一定是 Boss 或 Boss 技能。不要给任何普通物件用紫色。

### 2.3 配件稀有度（UI 与掉落光效共用）

| 稀有度 | 色值 | 视觉处理 |
|--------|------|----------|
| 起始 `Starter` | `#737A82` 灰 | 无光效 |
| 常见 `Common` | `#6B8E6B` 苔绿 | 无光效 |
| 稀有 `Rare` | `#5AA6F0` 蓝 | 卡面左侧色条 |
| 史诗 `Epic` | `#C76BF2` 紫 | 色条 + 轻微外发光 |

**注意**：史诗用紫，与 Boss 同色相。为避免混淆，配件紫只出现在**UI 平面**，世界内掉落物一律用白色光柱——不靠颜色区分掉落稀有度。

### 2.4 作用域标记（配件卡必备）

| 作用域 | 颜色 | 图标语义 |
|--------|------|----------|
| 全场 `Whole` | `#5AA6F0` 蓝 | 环绕全部子弹 |
| 后继 `After` | `#6BCB77` 绿 | 箭头指向后面 |
| 枪械 `Gun` | `#E8A33D` 金 | 枪形 |

**这三个颜色是世界信息的第二套编码**，全文档、UI、教程统一使用，不得替换。

### 2.5 配件圆形图标（2026-11-13 新增）

**所有出现配件的位置统一用"圆形图标 + 稀有度色环"代表它**，不再用文字缩写或方块占位：

| 位置 | 尺寸 | 附加信息 |
|------|------|----------|
| 背包格（紧凑卡） | 34 px | 无外环（24×44 的行高里外环会挤掉文字） |
| 链区卡片 | 48 px | 稀有度外环 + 右上作用域小标 |
| 三选一卡 | 96 px | 稀有度外环 + 作用域小标（玩家第一次见到该件的界面） |
| HUD 链条 | 40 px | 稀有度外环 + 右下触发序号 |
| 悬浮详情面板 | 52 px | 稀有度外环 |

素材契约：

- 文件名 `item_<配件 id>.png`，256×256，透明底，**暗色圆底板已烘进贴图**
  （因此不能用给黑底字形准备的加色材质，必须 `Image.Type.Simple` 普通混合）。
- 图形语言：暗金属圆盘 + 内层同心环 + 上缘高光弧 + 骨白字形，字形只表达该件的机制含义
  （例如 `m_split` 是一个圆分裂成三个，`b_pierce` 是穿透箭头），**不含文字**。
- 缺图时降级为"稀有度色块 + 名称首字"，绝不留空环或方块 —— 方块在一排圆形里看着像渲染错误。

## 3. 材质规范

| 类型 | Smoothness | Metallic | 用途 |
|------|------------|----------|------|
| 哑光混凝土 | 0.10 | 0.0 | 地面、掩体 |
| 拉丝金属 | 0.42 | 0.7 | 枪身、结构件 |
| 自发光 | — | — | 装饰带、危险液体、弹丸 |
| 敌人身体 | 0.30 | 0.1 | 保持轮廓清晰 |

**禁止**：玻璃、透明、折射、镜面金属（读图会变慢，且低模上很假）。

## 4. UI 规范

| 项 | 值 |
|----|-----|
| 参考分辨率 | 1600×900（`CanvasScaler` Match 0.5） |
| 面板底色 | `#0B0E12` @ 92% 不透明 |
| 面板描边 | 1px `#2A313B` |
| 主文字 | `#F0F4FA` |
| 次要文字 | `#9AA4B2` |
| 强调（数值） | `#F2C14E` 金 |
| 危险（血量/威胁） | `#E0474C` |
| 字体 | 内置 `LegacyRuntime.ttf`（初版）；正式版换思源黑体 Medium |
| 字号阶梯 | 54 / 40 / 30 / 26 / 22 / 20 / 18 / 17 / 16 / 15 / 13（不用 24、28 这类怪值） |

**HUD 纪律**：
- 十字准星必须随散射张开（`半径px = 8 + spread° × 4.5`，上限 90）。散射不可见＝配件差异不可感知。
- 轮转序列条必须常显。玩家看不到「下一发是哪个位」就无法做构筑决策。
- 数值文本一律带单位（`9.1 发/秒`、`1.20°`、`1.8s`），不要裸数字。

## 5. 特效规范

| 事件 | 表现 | 时长 |
|------|------|------|
| 开枪 | 枪口 2 帧高光 + 轻微后坐（`localPosition.z` −0.02） | 0.05 s |
| 普通命中 | 黄色小球扩散 | 0.08 s |
| 爆炸 | 半透明球体放大 + 亮度衰减 | 0.18 s |
| 敌人死亡 | 缩放至 0 + 少量碎块 | 0.15 s |
| 升级 | 屏幕边缘金色脉冲 | 0.5 s |
| 受击 | 屏幕边缘红晕（α ≤ 0.35） | 0.5 s |

**禁止**：长时间粒子、屏幕抖动（FPS 里会晕）、全屏闪白。

## 6. 素材规格与产出

| 资产 | 规格 | 产出方式 |
|------|------|----------|
| 掩体/结构 | 低模块体，单材质 | Blender 建模 + `blender-gate.ps1` 契约门 |
| 枪械第一人称模型 | ≤2500 三角面，无手部 | Blender；FBX 走 `Modle_*` 命名 |
| 敌人 | ≤1200 三角面，单骨架（可选） | Blender；`Anim_*` 命名 |
| UI 图标 | 128×128 PNG，透明底 | APIMart 生成后切图 |
| 配件圆形图标 | 256×256 PNG（内容为圆底板 + 亮色字形） | APIMart 生成 → 前期处理 → 几何合成，落 `Assets/Resources/UI/item_<id>.png` |
| 天光 | 渐变天空盒（程序化） | 代码生成，不用贴图 |

**Blender 交付纪律**（沿用工作区 `blender-asset-pipeline`）：
- 分件装配体不跑单体水密门，只跑契约门（`-ContractOnly`）。
- 导出前必须 apply 变换、单根、材质槽无空槽。
- UV 若用贴图，必须跑 `-UvUnwrap` 判可用性；纯色材质可跳过。

## 7. 当前实现与规范的差距（已知）

初版代码里所有物体都是 `GameObject.CreatePrimitive`（方块/胶囊/球），**没有任何自制模型**。差距清单：

| 规范要求 | 现状 |
|----------|------|
| 敌人有类型化轮廓 | 全部是胶囊体 + 颜色区分 |
| 枪械模型 | 一个方块 |
| 环境是「箱庭」多区域 | 单个 120×120 平面 + 随机方块 |
| 装饰带 / 危险液体 | 无 |
| 后处理 | 无 Volume Profile |

这些是拆解 P2/P3 的内容，不是缺陷——垂直切片先验证循环，再换皮。

## 8. 验收判据（美术）

1. 关掉 UI 只看画面，能在 3 秒内分辨「哪些是可走的、哪些是掩体、敌人是哪一类」。
2. 截图中至少两种敌人同时在视野内时，色相不混淆。
3. 任何界面文字在 1600×900 与 1280×720 下都不被裁切、不压花纹。
4. 配件卡的稀有度色条与作用域标签同时可见，且不靠颜色单独传达信息（有文字）。
