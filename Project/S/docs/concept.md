# 概念 — S

## 一句话

第一人称射击 + 局内构筑：你在一个会持续加压的**箱庭**里清场、吃经验、升级攒配件，然后把配件**拖进枪的配件位**里排成一条链条，用组合把一发子弹改造成完全不同的东西。

## 定位

| 项 | 值 |
|----|-----|
| 品类 | 第一人称射击（FPS）＋ 局内构筑 roguelite |
| 平台形态 | PC 键鼠 + 手柄，横屏，单局 25–35 分钟 |
| 视角 | 第一人称，自由视角，无锁定 |
| 操作 | WASD 移动、鼠标瞄准、左键射击、R 装填、Shift 冲刺、空格跳、Tab 开背包（**暂停**）、1/2 切枪 |
| 参考气质 | Noita 的**组合解谜感** × 现代 FPS 的**枪感与移动** × 箱庭式可持续加压的关卡 |

## 设计支点（三条，其余都从属）

1. **枪是容器，配件才是武器。**
   一把枪自己几乎不打伤害，它提供的是「配件位的数量 + 射速 + 弹匣」。真正的武器是你拼出来的链条。
   → 玩家每局最大的成就感来自「我做出一条能自我循环的链条」，而不是「我捡到一把更好的枪」。

2. **链条是有序的，顺序就是解法。**
   同一批配件换个顺序，结果完全不同（先加伤再分裂 ≠ 先分裂再加伤，见 `loadout-spec.md` §4）。
   → 拖拽不是整理，是编程。这是本作与普通 FPS 加装配件的根本区别。

3. **箱庭持续加压，逼你边走边改。**
   停留越久，威胁值越高；配件只能靠杀敌升级拿。
   → 玩家必须做「现在停下来改枪，还是再清一波」的取舍，构筑发生在战斗节奏里而不是菜单里。

## 核心循环

```
┌─ 局内（一局）───────────────────────────────────────────────┐
│                                                            │
│  进入箱庭 → 清区域 → 吃经验 → 升级 → 三选一配件 → 进背包   │
│      ↑                                    │                │
│      │                                    ↓                │
│  威胁值↑ / 更深区域 ←── 拖拽装链 / 换枪 ←── 打开背包(暂停)  │
│      │                                                     │
│      └──→ 区域首领 → Boss「铸造核心」 → 结算               │
│                                                            │
└────────────────────────────────────────────────────────────┘
          │死亡（配件/等级/枪全清）
          ↓
┌─ 局外（跨局）───────────────────────────────────────────────┐
│  少量永久解锁：起手枪池 +2、初始配件 1 个、图鉴、危险等级   │
└────────────────────────────────────────────────────────────┘
```

局内单循环（约 90–150 秒一轮）：

1. **清区域**：区域内有 3–5 波敌人，清空后门开。
2. **吃经验**：击杀掉经验球，靠近自动吸收。
3. **升级**：满经验立刻升级，弹三选一（配件）。选中的配件**先进背包**，不自动装上。
4. **改枪**：Tab 开背包（游戏暂停），把配件拖进配件位、排顺序、卸下来。
5. **推进**：进入更深区域，威胁值上升。

## 玩家每局要做的四个决策

| 决策 | 张力来源 |
|------|----------|
| **装满还是排好** | 配件位有限，同一条链同名配件最多 2 个；是把位塞满，还是留空给后面更好的 |
| **加法还是乘法** | 数值类按乘法叠乘（1.35^2 = 1.82），但会挤掉弹道/触发类的空间。纯数值流后期会被「需要穿透/范围」的敌人卡住 |
| **哪把枪吃哪些配件** | 携带 2 把枪，配件是共享资源。连发枪（3 位）适合铺多套循环，单发枪（1 位）适合把全部资源压进一发 |
| **什么时候停下来改** | 开背包即暂停，安全；但威胁值不因暂停停止上升的错觉，加上「配件在背包里就不算战力」，逼玩家尽快决定 |

## 为什么是「配件先进背包」

Noita 里拿到法术即刻生效，本作故意多加一步：
- 让**拖拽**成为真实的技能表达（同样是「+35% 伤害」，装错槽位等于浪费）。
- 让升级的即时反馈是「我多了一张牌」，而不是「我变强了」——变强要靠自己拼。
- 背包有容量（初版 24），满时升级的配件会**顶替**，逼玩家当场取舍。

## 范围与非目标

**初版做（垂直切片）**：

- 1 张箱庭（6 区域 + Boss 场）
- 3 把枪：连发 / 榴弹 / 单发
- 10 种子弹配件、15 种衍生配件（12 子弹向 + 3 枪械向）
- 4 种普通敌人 + 1 个 Boss
- 完整闭环：射 → 杀 → 升 → 选 → 拖 → 打得更狠
- 局外：起手枪池 + 解锁 2 个起始配件

**不做**：

- 联机 / 排行 / 内购 / 广告 SDK
- 多张箱庭、随机地图生成（初版箱庭是手工场景）
- 武器改造外观（配件只改数值与行为，不改模型）
- 技能树 / 天赋 / 角色差异化
- 载具、近战武器、手雷投掷（榴弹是枪械不是投掷物）
- 存档中途续玩（一局必须打完或死）
- 移动端适配
