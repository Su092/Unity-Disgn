# 概念 — S

## 一句话

第一人称射击 + 局内构筑：你在一个会持续加压的**箱庭**里清场、吃经验、升级攒配件，
然后把配件**拖进枪的配件位**里排好位置，用作用域组合把一发子弹改造成完全不同的东西。

## 定位

| 项 | 值 |
|----|-----|
| 品类 | 第一人称射击（FPS）＋ 局内构筑 roguelite |
| 平台形态 | PC 键鼠 + 手柄，横屏，单局 11–14 分钟 |
| 视角 | 第一人称，自由视角，无锁定 |
| 操作 | WASD 移动、鼠标瞄准、左键射击、R 装填、Shift 冲刺、空格跳、Tab 开背包（**暂停**）、1/2 切枪 |
| 参考气质 | Noita 的**组合解谜感** × 现代 FPS 的**枪感与移动** × 箱庭式可持续加压的关卡 |

## 设计支点（三条，其余都从属）

1. **枪是容器，配件才是武器。**
   一把枪自己几乎不打伤害，它提供的是「配件位的数量 + 射速 + 弹匣 + 读取数」。
   真正的武器是你排出来的那一格一格的组合。
   → 玩家每局最大的成就感来自「我拼出一条能自我放大的配置」，而不是「我捡到一把更好的枪」。

2. **位置就是解法。**
   同一批配件换个位置或换个作用域，结果完全不同：`伤害增幅` 放 `Next` 会占一次读取（少打一发别的），
   放 `Prev` 免费但只能影响左边最近的子弹，放 `All` 一次影响整把枪但只占一个格子。
   → 拖拽不是整理，是编程。这是本作与普通 FPS 加装配件的根本区别。

3. **单图持续加压，逼你边走边改。**
   一整张竞技场里无限刷怪，威胁值随存活时间上升，5:00 出精英、10:00 出 Boss。
   → 玩家必须做「现在停下来改枪，还是再清一波」的取舍，构筑发生在战斗节奏里而不是菜单里。

## 核心循环

```
┌─ 局内（一局，11–14 分钟）─────────────────────────────────┐
│                                                            │
│  进入竞技场 → 清场刷怪 → 吃经验 → 升级 → 三选一配件 → 背包 │
│      ↑                                    │                │
│      │                                    ↓                │
│  威胁值↑（按时间） ←── 拖拽装配 / 换枪 ←── 打开背包(暂停)   │
│      │                                                     │
│      ├──→ 5:00 首只精英（此后每 90 s 一只，共 4 只，击杀回血）│
│      └──→ 10:00 Boss「铸造核心」 → 击杀 → 结算（通关）      │
│                                                            │
└────────────────────────────────────────────────────────────┘
          │死亡（配件/等级/枪全清）
          ↓
┌─ 局外（跨局）───────────────────────────────────────────────┐
│  5 项永久解锁：第三把起手枪 + 4 个起始配件；图鉴             │
└────────────────────────────────────────────────────────────┘
```

局内单循环（约 45–90 秒一轮）：

1. **清场**：竞技场按时间轴持续刷怪，场上并发有上限（10→24），打完就有下一批。
2. **吃经验**：击杀掉经验球，3.5 m 内自动吸收。
3. **升级**：满经验立刻升级，弹三选一（配件）。选中的配件**先进背包**，不自动装上。
4. **装枪**：Tab 开背包（游戏暂停），把配件拖进配件位、挑作用域、卸下来。
5. **看时钟**：顶部大计时器显示存活时长与下一事件，10:00 前必须把清场效率做够。

## 玩家每局要做的四个决策

| 决策 | 张力来源 |
|------|----------|
| **填满还是留空** | 槽位有限（6–12 格），每一格要么放子弹要么放被动。填满会稀释「读到子弹」的密度，留空又浪费增伤位 |
| **放在谁的影响范围里** | 10 种作用域决定「一件被动影响几颗子弹、要付多少代价」。`Prev` 只作用于左侧最近一颗但免费；`N3` 覆盖右侧 3 格但要占住那一段的所有格位 |
| **哪把枪吃哪些配件** | 携带 2 把枪，配件是共享资源。霰弹枪读 2 发、发射器 12 槽、侦察枪零散射，各自适合完全不同的排法 |
| **什么时候停下来改** | 开背包即暂停，安全；但时钟在关掉背包后继续跑，10:00 的 Boss 不会等你。每次改装都在透支后面的余量 |

## 为什么是「配件先进背包」

Noita 里拿到法术即刻生效，本作故意多加一步：
- 让**拖拽与定位**成为真实的技能表达（同样是「伤害 +50%」，放错作用域等于白给）。
- 让升级的即时反馈是「我多了一张牌」，而不是「我变强了」——变强要靠自己排。
- 背包有容量（44），满时升级的配件会**顶替**，逼玩家当场取舍。

## 范围与非目标

**当前已做（垂直切片 + 原型对齐）**：

- 1 张箱庭（单张 100×100 竞技场 + 中央 Boss 台，无分区无门）
- 6 把枪：制式步枪 / 冲锋枪 / 战术霰弹枪 / 精确射手步枪 / 光束发射器 / 多功能发射器
- 配件共 51 件：子弹 17（含 7 种弹道形态 + 3 种触发）+ 子弹向衍生 13 + 枪械向衍生 9
- 10 种作用域（`Next` / `Prev` / `Adj` / `N2` / `N3` / `P2` / `All`）
- 4 种普通敌人 + 精英变体（5:00 起共 4 只）+ 1 个 Boss（三阶段 + 四能量柱）
- 完整闭环：射 → 杀 → 升 → 选 → 拖 → 打得更狠
- 局外：5 项解锁（第三把起手枪 + 4 个起始配件）+ 图鉴

**不做**：

- 联机 / 排行 / 内购 / 广告 SDK
- 多张箱庭、随机地图生成（当前箱庭是代码构建的固定场景）
- 武器改造外观（配件只改数值与行为，不改模型）
- 技能树 / 天赋 / 角色差异化
- 载具、近战武器、手雷投掷（榴弹是枪械不是投掷物）
- 存档中途续玩（一局必须打完或死）
- 移动端适配
