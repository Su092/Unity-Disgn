## 与工程的关系

- **文档只在枢纽**。工程内 `Assets/` 只放代码与运行时资源，不放过程文档。
- 唯一权威数值是 `unity/Assets/Resources/Data/sldata.json`（运行时读取）；
  `gameplay-spec.md` 是它的**人读镜像**。改数值必须两边一起改，否则文档会失真。
- 工程根 `README.md` 面向「打开工程就能跑」的人，只保留运行/验证/目录速览，
  设计细节全部指向本目录。

## 书写约定

- 先文档、再拆解、再实现；无文档依据不直接开做大块内容。
- 改设计时**整文件覆盖**对应 `docs/*.md`，禁止在文末叠「补充说明 / 另见」链。
- 实现任务写到 `../breakdown/`，不在 `docs/` 里堆待办清单。
- 数值一律写「当前值 + 出处字段名」，便于回查 `sldata.json`。
- 阶段性结论写 `../memory/`，不写进设计文档。
