# 概念 — 星轨防线

## 一句话

竖屏单屏星域塔防：**随机召唤 + 同级合成 + 三选一词条**滚雪球，同时手控一名英雄补火力，死守核心 10 波。

## 定位

| 项 | 值 |
|----|-----|
| 品类 | 单屏塔防（tower defense）＋ 局内肉鸽词条 |
| 平台形态 | 竖屏手游比例，单指可玩，一局 6–10 分钟 |
| 视角 | 固定俯视三追（相机只看战场，不做卷轴） |
| 操作 | 点击召唤/强化、拖拽换位与合成、点地控制英雄 |
| 参考气质 | 星际舰队塔防（Kingdom Rush 式塔位 + 刷怪车道）× 自走棋式随机与合成 |

## 核心循环

```
主菜单 → 编队（选 1–4 名干员）→ 选关 → 对局 10 波 → 结算
                ↑                                        │
                └──────────── 通关解锁下一关 ←───────────┘
```

局内循环（约 24 秒一波，共 10 波）：

1. **攒金币**：击杀奖励 + 每波结束奖励。
2. **召唤**：花金币从编队随机抽 1 座 1 级塔，落到已解锁的空塔台；价格逐次上涨。
3. **合成**：把同种同等级的塔拖到一起，等级 +1（上限 4 级），属性按等级幂增长。
4. **强化**：花金币抽 3 选 1 编队词条，全局生效且**不重复**，是本局的主要成长曲线。
5. **手控英雄**：点地移动，自动攻击范围内敌人；不死、不阻挡，是补漏的第二条火力线。

## 玩家每局要做的三个决策

| 决策 | 张力来源 |
|------|----------|
| **召唤还是强化** | 两条都涨价：召唤涨 1.28×、强化涨 1.42×。前期铺塔、后期押词条，比例决定强度曲线 |
| **铺开还是堆叠** | 塔台每召唤 3 次解锁 1 个（开局 6 个，最高 14 个）；铺开覆盖更多车道，堆叠获得高等级爆发 |
| **编队配比** | 编队只有 1–4 个干员，直接决定召唤池与可用词条池（词条按干员职业过滤） |

## 关卡结构

- 4 关同构：**固定 10 波**，第 5、8 波含精英，第 10 波 BOSS。
- 难度靠 `mul` 三件套（`hp` / `speed` / `reward`）与车道形状区分，不新增敌人类型。
- 车道为关卡内折线（10–46 个点），战场地图是 AI 生成的星球表面，**路线由代码按真实路径另画**。

## 范围与非目标

**做**：单屏塔防的核心手感、编队与词条深度、可复现的数值自检、竖屏 UI 与赛璐璐 3D 战场统一。

**不做**：

- 多场景切换（只有 `Main.unity`，其余全部代码构建）
- 联网 / 排行 / 内购 / 广告 SDK
- 英雄主动技能、多英雄同场
- 车道以外的小地图行军、地形机关
- 关卡编辑器对外发布（编辑器工具仅服务本项目自检与打包）
