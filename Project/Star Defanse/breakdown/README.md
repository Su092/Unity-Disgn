# 开发拆解 — 星轨防线

本目录存放「按 `docs/` 拆出的可执行开发切片」。实现时只改本游戏 `unity/` 工程。

## 使用方式

1. 确认 `docs/` 中对应规格已写清（数值看 `gameplay-spec.md`）
2. 在本目录新增或覆盖任务文件（`NN-主题.md`）
3. 任务文件必须含：目标、依据文档、改动路径、验收
4. 完成后更新 `../memory/CURRENT.md` 的状态

## 任务文件模板

```markdown
# 任务：标题

- 状态：未开始 | 进行中 | 完成
- 依据：docs/xxx.md
- 目标：……
- 改动范围：unity/Assets/…
- 步骤：……
- 验收：check.ps1 -Task tests / verify / build 全绿 + 截图确认
```
