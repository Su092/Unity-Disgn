# 《云端王国》概念 — 类星际拓荒方向

更新：2026-11-06  
来源：`docs/source/《云端王国》概念文档.docx`  
状态：**准备采用类《星际拓荒》有限箱庭方案**；概念熟悉阶段可制作底座，大块玩法内容仍按拆解推进。

## 世界观骨架

- **舞台**：蒸汽行星；无陆地；以**压力区**区分“深度/高度”，温度随压力递增。
- **分层**：底层为**临界态/超临界水**；中高层为云；中间有**过渡带**。
- **调性**：蒸汽朋克科技水平。
- **奇观**：神的调色盘（地磁异常）；部分云被地磁干扰凝固成固定形状。
- **资源与设施**：微量元素提取/精炼；**锁合粒子发生器**（可逆凝固，消耗粒子罐）。

## 交通 / 作业工具（设定层）

- **气囊飞行器**：压力差深潜/上浮；中层及过渡带浅层。
- **深潜器**：电磁炮式发射舱体；任务后控密度返回。
- **抗温压服**：深潜器出仓作业。
- **共生驯养式**：特殊生物 + 科技；抗高压高温；成本高。

## 玩法方向对照

| 方向 | 判断 |
|------|------|
| 模拟经营（浅层云海） | 深潜体验弱；偏小众 |
| 2D 潜水探索 | 深潜强，锁合/云海奇观难拉开差异 |
| 3D 开放世界 RPG | 成本高；后期难 |
| **类《星际拓荒》有限箱庭** | **当前方向**：世界观 > 玩法堆叠；重体验、轻/无战斗 |

## 选定方向要点

- 有限箱庭：可反复走通，靠理解推进。
- 探索驱动：**知识锁**（类银河恶魔城）。
- 科技碰撞：外来者 × 本地云端王国。
- 体验取向：重体验，轻战斗或无战斗。
