# 验收清单（独立验证者专用）

> **只读这一份。** 不要去加载整本 `SKILL.md` 或 `references/*` ——
> 验证者的固定开销就靠这条压下来。
>
> 目标：单次验证输入 ≈ 本文件（≈4k 字符）+ 回执 + 1–2 张图。

## 任务模板（直接复制给验证子代理）

```
你是**独立验证者**，不是构建者。只读本文件 + 我给你的回执与图。

- 输入：spec=<规格数值或路径>｜回执=<gate.json 路径或粘贴>｜图=<1-2 张同机位渲染图>｜变更=<改动的对象清单>
- 要求：
  1. 数值门自己跑，不许采信构建者的结论；
  2. 关键项必须换一条计算通路（见下"反 Goodhart"）；
  3. 按"输出格式"回 4 行，不要复述构建历史；
  4. 证据不足就写 unresolved，禁止在证据不足时二选一硬判。
```

## 数值门（脚本跑，别交给模型）

| 验什么 | 命令 | 通过判据 |
|---|---|---|
| 单件网格健康 | `-- mesh` | `verdict=pass`；`nonmanifold_edges=0` / `degenerate_faces=0` / `loose_verts=0` / `loose_edges=0` |
| 法线 | `-- normals` | `verdict=pass`，**且每个壳都 `pass`**（逐壳判，别只看聚合 `signed_volume`） |
| 埋面 | `-- buried` | `buried_count=0` |
| 自交 | `-- selfint` | `pair_count=0` |
| 壁厚 | `-- thickness --min-mm X` | `min_mm >= X` 且 `samples_below=0`；阈值 ≥ 分辨率 |
| 尺寸 | `-- measure --expect ... --tol-mm N` | `verdict=pass`，`out_of_tolerance=[]` |
| 装配浮空 | 见 `数值门.md` §7.1 | 无悬空件；**别拿"分量数=1"当判据** |
| 装配干涉 | 见 `数值门.md` §7.2 | 无异常互穿；允许的隐藏交叠已白名单化 |
| 交付完整性 | 自查 | manifest 齐全、单位盒归一化、贴图随包、md5 可复算 |

## 四条口径陷阱（否则会把结论读反）

### 1. ★ 三态，不是二态

`verdict` ∈ `pass` / `fail` / `degraded`。

**`degraded` 有两种读法都不对**：它不是"没过"，也不是"过了"，它是**没查完**。
处置是**补查** —— 加密网格、闭合网格、提高采样、放开被跳过的检查。

见到 `verdict=degraded` **先读 `notes` / `error`**，再决定是改几何还是改判据。
`pair_count=null`、`min_mm=null`、`analyzed=false` 同理：**都不是通过**。

### 2. 法线别看聚合值

聚合 `signed_volume` 把所有壳**相加**：大正向壳 + 分离的小反向壳仍可能为正。
必须看**逐壳** `state`。`n/a`（未闭合）**一律不给 pass**。

### 3. 逐轴 AABB 重叠是粗筛，不是结论

- 只在"接口法线与某根世界轴一致、且轴对齐盒适用"时读**那一根轴**；
- 旋转 / 斜置接口必须沿真实接口局部坐标量真实表面；
- 全内含浮块也可能给出三轴正重叠 ⇒ 须结合浮空与干涉检查；
- `volume_mm3` 是交集体积，**不能代替**接口深度或结构强度。

### 4. 未求值 vs 求值

`-- mesh` 读**未求值**的 `ob.data`：未 apply 的修改器**不算数**
（带 Mirror 的半个件会报基础网格的 `verts=4 / boundary_edges=4`）。
`-- measure` 与 `-- buried` / `-- selfint` 走**求值网格**（Boolean 未 apply 也算数）。

**两者别混。** 要判"改完没有"，先 apply 掉相关修改器。

## 反 Goodhart：什么叫"换一条计算通路"

同一件事**不许**用构建时那条通路复核。判据：**换通路后，若构建逻辑本身有 bug，结论会翻转。**

| 构建用了 | 验证必须换成 |
|---|---|
| `Object.dimensions`（局部 bbox × scale，**不含旋转**） | `matrix_world @ v.co` 求世界 AABB |
| 内环优化的 best score | 独立脚本复算，不读内环的 best |
| 导出器自检 | 对导出文件复算 md5 + 单位盒 |
| "看起来对" | **数值 + 画面**两条证据（缺一不可） |

## 主观门（只有这类需要陌生视角）

"像不像参考图 / 构图 / 配色 / 排版 / 文案"：

1. 先用同机位渲染 + IoU 拿**数值**（IoU / 剖面差）；
2. 再由你看图下结论；
3. **图 ≤2 张**，不要全场景重渲；
4. 主体占画面 <5% 的图**直接判无效重拍**。

> ⚠ **IoU 只是"该视图下轮廓重合度"**，是**必要不充分**条件。它看不见：
> 深度/厚度、内部特征（板缝/格栅/灯/特征线位置）、曲面张力（面感）、其他视图。
> 而且"把轮廓填满"就能刷高它。
>
> ⇒ 见到"IoU 0.9"**不要**直接判 pass：至少要求**多个视图各自算** + 一张特征线对照 + 间隙检查；
> 发现"IoU 涨了但图更难看了"就判 `unresolved`，并指出是哪一层错（包络 / 站表 / 特征线）。

## 输出格式（固定 4 行，超了就删）

```
verdict: pass | fail | unresolved
evidence: <门名 + 关键字段 + 实测数值>（1-3 行，必须可复现）
failures: <不达标项 ≤3 条：对象 / 字段 / 实测值 / 阈值>
repro: <能重跑出同一结论的命令>
```

## 自查（跑偏的信号）

- 你正在读 `SKILL.md` 或 `references/六条坑.md` ⇒ **停**，改读本文件；
- 你在复述构建步骤 ⇒ 删掉，只留证据行；
- 你准备"全场景重新体检一遍" ⇒ 先想：能不能只验差异（变更清单）；
- 你打算写"应该没问题" ⇒ 那是 `unresolved`，或者去补一条证据；
- 你把 `degraded` 写成了 pass 或 fail ⇒ 回去读口径陷阱 §1。
