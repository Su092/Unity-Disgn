# 参考图通用还原 SOP

> 一句话：**几何机制与类别无关** —— 先量（无标定不写 mm）→ 放样/反推 → 特征线 → 同机位验收。
> 换类别只换协议（视图 / 比例 / 验收门）。

## 0. 适用与不适用

| | 对象 |
|---|---|
| **适用** | 有明确外轮廓、能用正交视图描述的：车辆 / 人形 / 动物 / 家具 / 头盔 / 船体 / 飞机 / 枪械 / 道具 / 建筑构件 |
| **需变体** | 轴对称（→ 旋转体）/ 多体量（→ 分区装配）/ 只做一半（对称件）/ 柔性但成形（坐垫） |
| **不适用** | 没有外轮廓的（布料 / 毛发 / 流体 / 烟）/ 靠内部结构定义的（多孔晶格 / 拓扑优化件） |

## 1. 九步（S0 草稿 → 每步都有数字）

> **⓪ 步是草稿，不是规格**：这一步**不量精确尺寸、不数 mesh、不把数字定死**。
> 它只回答六件事：是什么 / 大概多大（只给量级档）/ 拆成几块 / 谁是主体谁是配件 /
> 哪块硬表面哪块曲面 / 哪里镂空·凸起·凹陷。
> 拿到参考图之后，才从 ① 步开始把草稿**逐行**补成数字；草稿里的粗数字**不继承**为规格。

| 步 | 动作 | 产出 / 判据 |
|---|---|---|
| ⓪ | **草稿评估**（在脑子里打草稿） | 四张表（T1 识别与量级 / T2 制作单元 / T3 形态 / T4 空间特征）；判据 = 无 mm 级绝对值、无空缺字段。**本步禁跑任何数值门，不出任何 mm** |
| ① | 校正 | 正交图 + `mm_per_px`；**照片必做**，但只对"取点那个平面"成立（见 §3.1） |
| ② | 量包络 | 长/宽/高 + 类别比例；**不过比例门别往下做** |
| ③ | 量站表 | 侧视逐列上下边界 + 俯视半宽 + 前视截面轮廓 |
| ④ | 放样 | 站表定轮廓、截面轮廓定性格 |
| ⑤ | 特征线 | 硬折线（真圆角）+ 折面凹槽 → 面感参数化 |
| ⑥ | 参数化（可选） | 可改数字的 spec；**族外形状轮廓 IoU 会卡在 ~0.82** |
| ⑦ | 多体量 / 缝 | 每块一个体量；缝是真几何（用间隙检查量） |
| ⑧ | 验收 | **每个视图各自算 IoU** + 尺寸/比例/间隙数字（IoU 只判轮廓，见 §4） |

### 1.1 ⓪ 步的四张表

| 表 | 判什么 | 怎么做 | 草稿期精度 |
|---|---|---|---|
| **T1 识别与量级** | 是什么 / 归哪类 / 大概多大 / 对称与轴向 | 直接命名 → 归类；尺寸用**对数档 A–F**（<10cm / 10–30cm / 0.3–1m / 1–3m / 3–10m / >10m）+ 人体尺度锚（掌上 / 单手 / 怀抱 / 一人高 / 车长 / 建筑） | 只有档位，**无 mm** |
| **T2 制作单元**（核心） | 有哪些件、谁是主体谁是配件 | 语义命名 → `role`：① 占包络主要体量 ② 被 2 个以上件挂靠 ③ 少了它整体不成立 —— **满足①即主体**，其余配件/重复件 → `parent` 装配树 | 主体唯一（多体量可并列），可改 |
| **T3 形态** | 硬表面还是曲面 | 7 类定性判据：`faceted` / `smooth` / `organic` / `rotational` / `plate` / `repeats` / `sweep`。**混合体按件分别标**（角色 = 有机身体 + 硬表面装备） | 只判面感，不判半径/段数 |
| **T4 空间特征** | 镂空 / 凸起 / 凹陷 / 缝 / 薄壁 / 格栅 | 每处一行：`kind` + `where`（部件 + 上中下/前后）+ 数量级（1 / 数个 / 阵列）；镂空标 通/盲 | 不算孔径、深度、壁厚 |

**S0 三条硬规则**：

1. **R1 不量精确尺寸** —— 尺寸字段只能是量级档或相对比例（如 `0.3×`）；出现 mm/cm 级绝对值即拒收。
2. **R2 不数 mesh** —— 禁跑数值门；只允许 `part_count_hint` 这种量级估计。
3. **R3 不定死数据** —— 每字段带 `confidence`(high/mid/low) 与 `source`，判不出写 `unknown`；
   **每件必须带 `to_confirm`**（这一列就是"图来了要补什么"的销项清单）。

> 为什么单列 R3：草稿阶段最贵的错误不是判错，而是**把判错的东西写成了规格** ——
> 后面所有人照着错数字建，返工成本是全量。

## 2. 选哪条截面通路（决策规则）

1. **轴对称**（瓶 / 罐 / 轮毂 / 花瓶 / 喷口）⇒ **旋转体**（profile 绕轴）—— **不要**用放样
2. **左右对称 + 前视有轮廓** ⇒ 归一化逐行宽度，按站点半宽缩放
3. **有弯度 / 左右不对称 / 要精确控制截面**（翼型、机匣、异形件）⇒ **显式闭合轮廓**按站归一
4. **只有一条侧视轮廓、截面随长度基本不变**（板件、型材）⇒ 超椭圆截面 + 特征线即可
5. **多体量** ⇒ 分区各自建模，装配后用间隙检查

> 前视逐行宽度那条路**必然左右对称**；翼型必须走第 3 条。

### 2.1 类别协议速查

| 类别 | 视图 | 关键比例 | 主要坑 |
|---|---|---|---|
| vehicle | 侧 前 顶 | 轮距/轴距比 / 高长比 / 前后悬 | **轮径不可从轮廓反推**；没俯视图车身偏窄 |
| humanoid | 侧 前 | 头身比 7–8 / 肩宽 ≈ 1.5 头高 | 写实脸做不到 → 面罩/简化遮 |
| creature | 侧 前 顶 | 身长/肩高 / 头长/身长 | 四足 ≠ 双足比例；毛发不适用 |
| headwear | 侧 前 顶 | 头高:宽:深 ≈ 233:175:206；眼线 0.50 / 鼻底 0.725 / 嘴线 0.825 | 内腔留头围余量 |
| furniture | 侧 前 | 座高 / 座深 / 靠背倾角 | 人体工学优先于外形相似 |
| hull | 侧 顶 | 船长 / 船宽 / 型深 | **水线上下要分别给站表** |
| aircraft | 侧 前 顶 | 翼展/机身长 / 弦长分布 | 机翼用**翼型截面**不是超椭圆 |
| rotational | 侧（单轮廓） | 高/直径 / 最大直径位置 | **别用放样** |
| weapon | 侧 顶 | 总长 / 握把位置 | 握持尺寸是硬约束 |
| generic | 侧 前（+顶） | 先量三包络比 | 照片先校正 |

## 3. 三个决定性细节（都是实测踩出来的）

1. **没有俯视图就没有平面收放**：只有侧+前视时半宽缺失，车身会窄成 460 mm（应 1850 mm）。
   必须用"前视最大宽 × 收放假设"回填，**并在回执里标注这是假设**。
2. **轮径 / 接地体不能从填充轮廓反推**（轮与车身连成一片）；但**轮轴位置可以**（轮廓底部低洼段聚类）。
3. **特征线不能按 z 带匹配边**（环上顶点离散，目标高度常常没有边 → 0 命中）；
   要用**环索引**；横向特征线还要**自动插站**。

### 3.1 单应校正只能校正一个平面（★ 最容易高估的精度）

四点单应对**恰好落在取点那个物理平面**上的点严格成立；离开该平面的点误差随深度迅速放大。

实测（在 z=0 平面拟合单应；该机位 1 m ≈ 190 px）：

| 点离 z=0 平面的距离 | 最大误差 | 折算 |
|---|---|---|
| 0 m | **0.000 px** | 0 mm |
| 0.05 m | 9.906 px | **52 mm** |
| 0.20 m | 40.194 px | **211 mm** |
| 0.50 m | 103.464 px | **543 mm** |

⇒ **平面参考**（图纸翻拍 / 标定板 / 贴平的贴纸 / 地面标定框）完全正确；
**立体物**（车 / 人 / 建筑 / 头盔）只有取点那个平面准 —— 轮眉外扩、翼子板弧度、A 柱前倾、
鼻锥纵深这些**离平面远**的特征，量出来是错的。

要么只量靠近该平面的尺寸，要么改走**真正的相机标定（内参 + 外参，多视几何）** —— **不是**单应。

### 3.2 跨深度误差不是 ±5%

透视下比例随深度按 `1/z` 变化，误差上界可算：

```
err ≈ Δz / (D + Δz)        D = 相机到近处标尺距离，Δz = 深度差
```

实测（D = 8 m）：`Δz=0.5m → −5.88%`；`Δz=1m → −11.1%`；`Δz=3m → −27.3%` —— 与解析式逐行吻合。

⇒ **只跨 0.5 m 就已超出 ±5%。** 估不出 `D` / `Δz` 就记 `unresolved`，别写"±5% 应该够"。

## 4. 验收纪律

- **数值门自己跑**：脚本判据，不需要模型判断；回执大就只要汇总字段。
- **只有主观项**（"这个面感对不对"）才需要陌生视角；给它 `references/验收清单.md`，别给整本 SKILL.md。
- **每个视图的 IoU 分开算**：侧视最容易先到 0.9+，顶视最难（平面收放全靠它）。

### ★ IoU 是必要不充分条件

IoU 只是"该视图下轮廓重合度"。它**看不见**：

- 深度 / 厚度
- 内部特征（板缝 / 格栅 / 灯 / 面罩 / 特征线位置）
- 曲面张力（面感）
- 其他视图
- 体积分布

而且**"把轮廓填满"就能刷高它**。

⇒ IoU 达标**只能推翻"轮廓错"**，不能证明"像"。必须配：
间隙检查 + 尺寸门 + 特征线对照。

**别把 IoU 当交付目标去凑。**

### IoU 到不了就回看是哪一层错

| 症状 | 哪层错 | 改什么 |
|---|---|---|
| 包络比例不对 | ② | 改包络 |
| 侧视 IoU 低 | ③ | 改站表 |
| IoU 高但看着不对 | ⑤ | 改特征线 / 圆角 |

## 5. 草稿 → 数字的迭代纪律（S0 → S5）

| 阶段 | 允许产出 | 禁止 |
|---|---|---|
| **S0 草稿**（无图） | 品类、量级档 A–F、部件拆分、主体/配件、形态与空间定性 | 任何 mm；对象/面数统计；把数字写进 spec |
| S1 读图 | bbox / 长宽比 / 主轴角 / 孔 / 可读性；局部量 | **把像素当毫米**（像素 ≠ mm） |
| S2 标定 | 已知边长 / 两点 → `px_per_mm` → 包络 mm（**第一次出现数字**） | 把 S0 的粗档当实测值；无标定写 mm |
| S3 站表 / 截面 | 站表 + 截面轮廓（此时 mm 自由） | 跳过 ①②③ 直接放样 |
| S4 出图对照 | 逐视图 IoU + 特征线对照 | 拿单视 IoU 当"像"的证明 |
| S5 验收 | 跑全套数值门（**这一步才**数面数、量间隙） | `degraded` 当通过 |

**字段升级要留痕**：任何值从 `provisional` 变 `confirmed`，记下"由哪张图 / 哪次回执确认"。
S0 的档位只用于**选路**（选截面通路、定分工），**不用于填 spec** —— 这就是"不打草稿定死"的操作口径。
